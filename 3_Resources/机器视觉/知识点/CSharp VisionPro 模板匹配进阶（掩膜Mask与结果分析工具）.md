# C# VisionPro 模板匹配进阶（掩膜 Mask / 结果分析工具）

8.24 下午（2）的课，接着下午 1 的 VisionPro 模板匹配，讲**进阶用法**：投影仪点数 + 硬币案例——用**掩膜（Mask）**一个工具同时匹配正反面，再用**结果分析工具（CogResultsAnalysisTool）**算出总金额。

> 📌 这课把模板匹配的原理彻底讲透了（小绿线描特征），还引入了**掩膜**和**结果分析**两个新工具。跟下午 1 是一条线，机器视觉的活儿越来越像样了。

## 🧩 开胃菜：投影仪点数案例

素材是**投影仪（彩图）**，要点出**点数**。

- 彩图做不了模板匹配 → 先**彩转灰** → 在灰度图上做模板匹配
- ⚠️ 模板匹配**连的是转灰后的图**，不是原彩图
- 框住其中一个点当模板（挑"中间的好看点"）→ 中心原点 → 训练 → 运行
- 点数多，**覆盖数设 50**；有**红框就适当降低预值**让它匹配出来
- 文字工具连**彩色图**展示（文字工具图彩色/灰度都行，模板匹配挑，文字不挑）

### 💡 圆形模板：不一定设旋转角

- 模板是个**圆**，怎么转都是圆 → **没必要设旋转角**
- 硬要设反而**增大误差**：同一个圆可能被匹配两次（正着配一次、歪着配一次），分数还差不大
- 结论：**极少数情况可以不设旋转角**（目标本身旋转不变时）

## 🧩 硬币案例：计算每一张图的总金额

素材：各种硬币（一毛/五毛/一元，正反面都有）。要做的是**算出每张图片的总金额**。

- 例图：2 个一元 + 2 个五毛 + 2 个一毛 = 2.1 元
- 💰 **应用价值**：找齿数/点数这些（螺旋架点数、车毂）、医药/食品不能用（卖一座的钱数能一样吗）。能用到的是**收到投币的场合**——比如游乐场投币，自动识别一堆硬币算出总金额，老板省事。

### 思路：金额 = 面值 × 数量

- 要算总金额 = 各硬币**面值 × 数量** 再相加
- 面值已知（一毛/五毛/一元），关键转成**求各自数量**
- 一元有正反 → 原本得**正面匹配一次 + 反面匹配一次**再加起来 → 每个币种 2 个模板匹配，一个项目要 6 个，**工作量太大**

### ⚠️ 找模板要挑"独立"的

- 找元硬币模板时，**一定要找单独（老的）硬币**，别找挨着一块儿的
- 挨着的话难免把**别的硬币的特征也算进来**，误差就大了

## 🧩 进阶：模板匹配的原理（小绿线）

在模板匹配界面 → 切到**训练图像** → 切到**图形**那一栏 → 勾上 **显示粗糙 / 显示精细**：

- 就能看到模板匹配在框住的区域上，用**小绿线把特征都描出来**（轮廓、文字、图案）
- **模板匹配的原理**：训练时把框住区域的特征全部勾勒成模板；运行时拿这些特征去图里找同样的东西
- 一元正面特征：大"壹"字、轮廓、2014 数字、"壹圆"、中文、两圈圆……等等

## 🧩 关键进阶：掩膜（Mask）——一个工具同时匹配正反面

想用一个模板匹配同时找一元**正和反**：正反面的**共同特征**就是最外层的**两圈圆**（正面有字+圆，反面是花+圆，共同的是圆）。

### 掩膜的作用

- **掩膜 = 把不需要的特征掩盖掉**，只保留要用的共同特征
- 只留最外两圈圆 → 一个模板匹配就能同时匹配正面和反面

### 操作步骤

1. 先把一元**正面**单独匹配出来，切到训练图像，图形栏勾显示粗糙/精细
2. 点最上边一横排按钮里的**图像掩膜编辑器**（图标是拿笔画的）→ 进入画图界面
3. 用**笔刷**调大，有三种颜色：**橡皮擦**（涂错了擦）/ **红色**（掩膜像素，盖掉不要的特征）/ **黄绿**（忽略杂斑，暂时用不到）
4. 用红色把一元正面**内部不需要的特征**涂掉（文字、数字、中间全涂），**只留最外两圈圆**
5. 点**确定** → 回去看图像被盖了一层
6. 因为对源头做了操作，**模板会消失 → 再训练一次**
7. 运行 → 特征就剩最外两圈 → **一元正面反面都能找到了！**

## 🧩 新工具：结果分析工具 CogResultsAnalysisTool（算总金额）

工具箱 → 常见控件里**倒数第 4 个** → 图标全是一堆数学符号 → **CogResultsAnalysisTool**（结果 + Analysis 分析）。

- ⭐ 它**不需要图片**（计算要图片干嘛）→ 作业编辑器里就孤零零一个工具
- **没有自带输入/输出**：计算前提条件各不一样，输入输出由工程师**自己设置**
- 双击进入，是个**表格**结构，用来做计算

### 表格的列

| 列 | 干什么 |
|---|---|
| 名称 | 起个名 |
| 参数0 | 运算的一个输入 |
| 运算符 | 加减乘除 |
| 参数1 | 运算的另一个输入 |
| 值 | 运算结果 |
| 输出(勾选框) | 勾上了就输出，不勾不输出 |

### 左上角三个图标

1. **fx**（函数）：点一下加一行用于计算的函数
2. **单输入**：传一个值（用它）
3. **多输入**：一口子拿多个数据（难用，之后学脚本更方便，几乎用不到）

### 第一步：把三个硬币数量传进来

- 用模板匹配把一元/五毛/一角各自的**数量（Count）**先添加出来
- 加三个**单输入** → 创建 input a/b/c → 连上三个模板匹配的 Count
- 改名为：**一元的数量 / 五角的数量 / 一角的数量**（比 input abc 好看好记）

### 第二步：算各自的金额

- 加 3 个 **fx 函数**，改名为「一元的金额 / 五角的金额 / 一角的金额」
- 金额 = 数量 × 面值，**运算符用乘**：
  - 一元金额 = 一元的数量 × **1**
  - 五角金额 = 五角的数量 × **0.5**
  - 一角金额 = 一角的数量 × **0.1**

### 第三步：算总金额

- ⚠️ 这个工具**只能两两计算**，三个相加要**加两次**
- 先一元+五角，再把结果和**一角**加起来 → 总金额
- 把总金额那一列的**勾选框勾上** → 作业编辑器输出出来
- ⚠️ 万一不小心勾了别的输出，这里**取消不掉**，只能回作业编辑器**手动断开**删除
- 算完**一定要运行**（这是个工具）！总金额就出来了

## 🧩 把总金额显示到图上（类型转换小坑）

按老办法用**文字工具**连总金额的 double → **连不了**！

- 选中总金额右键 → **连接修改** → 发现它的值 **Value 是 object 类型**
- 虽然能拆箱装箱，但它**不让转（有风险）**
- 解决：Value 左边有**加号 → 展开 → 里面有个 double** → 选中它点 OK → 把值**手动改成 double**
- 改完还是 2.8，但类型对了就能连了 → 连上文字工具 → 设字体/位置 → 运行

⚠️ **改不了 double 的两个点**：
1. 如果右键修改**没有 double 选项** → 你的工具**没运行**，运行之后才能改
2. 总金额那列要先**勾选输出**，才有得连

## 🧠 一句话总结

1. **圆形/旋转不变的目标** → 可以不设旋转角（设了反而增大误差）
2. **模板匹配原理**：训练时描特征成模板，运行时拿特征去匹配（图形栏勾显示粗糙/精细能看见那些小绿线）
3. **掩膜 Mask** = 把不要的特征涂掉，只留共同特征 → **一个模板匹配同时匹配正反面**
4. **结果分析工具 CogResultsAnalysisTool**：表格算数，只能两两算；单输入收数 → 乘面值得金额 → 加起来得总金额 → 勾选输出
5. **连文字工具**：Value 是 object 类型连不了，右键连接修改**手动改成 double**（要先运行才能改）

## 📚 作业

1. 投影仪点数案例：彩转灰 → 模板匹配点数（覆盖数50，红框降预值）→ 文字工具在彩图上显示
2. 硬币案例：用**掩膜**只留两圈圆，一个模板匹配同时找一元/五毛/一角的**正反面**
3. 用**结果分析工具**把三个数量 × 面值算各自金额，再加起来算**总金额**
4. 把总金额用文字工具**动态显示**到图上（记得右键连接修改改成 double）
