# C# VisionPro 图像形态学处理（腐蚀 / 膨胀 / 开运算 / 闭运算）

8.27 上午的课，**深化 Blob 工具**的形态调整。上节课（8.26）学的 Blob + 颜色分割能数斑点，但真实拍摄的糖果/胶囊**受光照影响颜色有深有浅、有孔洞毛刺**，直接 Blob 数不准。这节课学**图像形态学处理**——把关斑点"修饱满、修干净"再数。这是 Blob 数量检测篇的进阶。

> 📌 核心：**图像形态学 = 处理斑点形状的两个操作（腐蚀、膨胀）**，再组合出开/闭运算。它是"视觉里经常用的技术"，专门消除拍照带来的**孔洞、毛刺、小碎斑**，让斑点变饱满好计数。

## 🎯 为什么需要它（光照下的真实问题）

- 之前做的**橙色胶囊**是**纯色**，提取一个颜色就全出来了
- 但**拍照有光**，光反射到物体上 → 同一颜色会**有浅有深**（浅红/正常红/深红、浅蓝/正常蓝/深蓝）
- 用颜色分割后：颜色不饱满 → 斑点里有**孔洞**、外面有**小毛刺/碎斑** → **Blob 直接数会数不准**（把孔洞算进去、毛刺干扰）
- 为什么不用**最小面积**直接把小孔洞/碎斑去掉？——因为斑点大小不一，设最小面积会**把小的好糖果也削掉**（糖果有大的有小的）

## 🧩 糖果案例（第一张图的完整思路）

1. **颜色分割工具**：把红色糖果割出来。因为光照有深有浅 → **多提取几次红色**（浅红、正常红、深红都加），让糖果分割得**越饱满越好**
2. ⚠️ **别把白色反光也提取**：背景是白的，你把反光白也提取下来 → 背景和糖果混一起，反而不准
3. 割完后，Blob 工具里先看到**显示重叠结果**把原图盖住 → 去"图形"页把**显示重叠结果关掉**恢复原图
4. **Blob 工具**：设**黑底白点**（分割后背景黑、糖果变白斑）→ 运行
5. 这时看到糖果上有**孔洞**、斑**破碎** → 上**图像形态学处理**修饱满（核心）

## ✅ 图像形态学处理：两个基本操作

**腐蚀（Erode）**：把斑点**四周的像素削掉一圈**（消除边缘）。→ 削掉毛刺、小凸起、把相邻斑点的"桥"断开
**膨胀（Dilate）**：把斑点**四周的像素增加一圈**（填充边缘）。→ 填充孔洞、裂缝、把碎斑连起来

### Blob 里的位置：形态调整操作

- 在 **Blob 工具左边下方**，叫 **形态调整操作**（一个表格）
- 左上角**新增** → 下拉选操作，有 6 个基础项：
  - **清除/腐蚀 三个**：清除正方形、清除水平面、清除垂直面
  - **扩大/膨胀 三个**：扩大正方形、扩大水平面、扩大垂直面
- ⚠️ 软件汉化可能写"清除/扩大"，意思就是**腐蚀/膨胀**，别被字面骗了
- **正方形 = 四周一圈都操作**；**水平面 = 只操作左右（上下不动）**；**垂直面 = 只操作上下**（左右不动）
- 一般**用正方形**就行，除非素材特殊才用水平/垂直面

### 腐蚀 / 膨胀的底层原理（十字准心对比法，老师用 Excel 表格演示）

- 用一个**十字准心结构**（中间像素格 + 上/下/左/右四个角）去一一比对斑点
- **腐蚀**：把十字准心贴到每个像素格，**如果上下左右四个角能正好全部装下**（四周都有像素）→ 中间那格**保留**；装不下 → **去掉**。结果 = 把鼓出去的小角都削掉（一圈薄化）
- **膨胀**：把中心对准某个像素格，**上下左右哪些方向是空的（没被填）→ 就填上**；已经填的不动。结果 = 四周空白处补一圈
- **开/闭运算** = 在腐蚀/膨胀基础上**再套一层**，作用就体现出来了

## ✅ 开运算（Opening）与 闭运算（Closing）

**定义（记牢）**：
- **开运算 = 先腐蚀 → 后膨胀**（"后膨胀=打开"所以叫开运算）→ 消除斑点**外部**的散碎
- **闭运算 = 先膨胀 → 后腐蚀**（"后腐蚀=关闭"所以叫闭运算）→ 填充斑点**内部**的空洞

### 开运算作用（去外部小碎）
- **消除物体四周的毛刺、小凸起**
- **分开相邻连在一起的斑点**（两个斑点中间有一小条像素线连着 → 先腐蚀把线腐蚀断 → 再膨胀线不会回来 → 分开）
- **消除孤立的小点/碎斑**（先腐蚀小点没了 → 膨胀原斑点没变回去、小点不会再出现）

### 闭运算作用（填内部空洞）
- **填充斑点内部的细小孔洞**：先膨胀把内部孔洞填掉 → 腐蚀回去 → 填掉的孔洞**不会再出现**
- **填充内部小裂缝**：位置和形状不变，只是把洞填上

> ⚠️ **闭运算只能填小孔洞**。糖果案例里：用一次"关闭正方形"填掉大部分小孔洞后，**还剩几个大孔洞填不掉**——因为这里的形态学操作**只做一倍**（一次膨胀+一次腐蚀），大孔洞做一次填不掉。
> **解法：做"多倍闭运算"**——手动拆开：**先多次"扩大"把大孔洞也填掉（扩到孔洞全部消失）→ 再多次"腐蚀"回去**。糖果案例就是**扩大7次 → 腐蚀7次**，糖果变特别饱满，数点就好数了。

## ⚡ 小技巧：电子模式（避免反复点运行）

- 以前加一个形态操作要**运行一次、加一次、运行一次**，太麻烦
- 把 **电子模式 勾上**（Blob/形态工具里那个**小闪电按钮**，第一周讲 VisionPro 时说"用到再讲"）
- 勾上后参数会带上**小闪电图标**；鼠标放上去显示"**改变该设置将重新运行该工具**"→ 每改一个参数**自动运行一次**，不用手动反复点运行
- 调"扩大几次"时用它特别省事

## 🧩 完整流程（糖果 + 胶囊药品案例通用）

1. **颜色分割工具**（CogColorSegmenter2）：光线有深浅 → **选区域取平均色 + 提多个深浅颜色**，让轮廓分割饱满（胶囊提了6个颜色）
2. 接 **Blob 工具**：设**黑底白点** → 运行 → 看到斑点上有很多孔洞
3. **图像形态学处理**（重点）：因要**填内部孔洞** → 用**多倍闭运算 = 先扩大(填洞) → 后腐蚀(收回去)**
   - 勾上**电子模式**，**扩大正方形**（扩到内部孔洞全部消失，胶囊扩了几次）→ 再**腐蚀正方形**（同样次数收回去）
4. 之后斑点就**饱满**了；若还有细碎小斑 → **最小面积**排掉（胶囊案例最小的合格胶囊约1900，最小面积设500先把碎斑排掉）
5. **文字工具 CogGraphicLabel** 把数量显示到图上：合格胶囊约4000/3900/3800，**一半的坏胶囊只有2000** → 最小面积设**2500**把不合格的都排掉 → 数出合格胶囊数量（案例里13/14/15/12/15个）
6. 切换到其他图看效果，确认都准

## 🧠 一句话总结

1. **光照**让物体颜色**有深有浅** → 颜色分割要**多提几次深浅色**，别把**白反光**也提了
2. **图像形态学 = 腐蚀 + 膨胀**；腐蚀削四周、膨胀填四周；**正方形**四周都动，水平/垂直面只动一边
3. **开运算 = 先腐蚀后膨胀**（去外部毛刺/碎斑/断桥）；**闭运算 = 先膨胀后腐蚀**（填内部小孔洞/裂缝）
4. **大孔洞一倍闭运算填不掉** → 拆成**多倍=先多次扩大再多次腐蚀**（糖果扩大7次腐蚀7次）
5. **电子模式（小闪电）**勾上 = 改参数自动运行，调形态次数超省事
6. 形态做完还有碎斑 → **最小面积**排掉；要只留合格件 → 最小面积设成"合格件面积与坏件面积之间"（2500卡掉一半的2000）

## 📚 作业 / 练习

1. **糖果案例**：颜色分割（多提深浅红）→ Blob 黑底白点 → 图像形态学（多倍闭运算扩大7腐蚀7）→ 孔洞消失、糖果饱满 → 数出红色糖果数量
2. **胶囊药品案例**（难度略高）：颜色分割选区域取平均色提6色 → Blob → 黑底白点 → 多倍闭运算（扩大填洞→腐蚀收回）→ 最小面积500排碎斑 → 最小面积2500只留合格胶囊 → 文字工具显示数量
3. **手动验证原理**：创建一个 Excel 表格（把行裂宽设6、航高设30，让每格接近正方形），涂一个图形，用**十字准心法**手动做一次**腐蚀**和**膨胀**，看图形分别变成什么样，理解"装得下保留/装不下去掉"和"空格填上"
