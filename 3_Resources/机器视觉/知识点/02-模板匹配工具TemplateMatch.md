# 🎯 模板匹配工具 TemplateMatch

> 机器视觉第二个工具。对标 **VisionPro 的 CogPMAlignTool** / **OpenCV 的 Cv2.MatchTemplate**。
> 课程来源：`14班8.24上午.mp4`（VisionPro 软件实操，1小时16分）。

## 模板匹配是啥（大白话）

拿一张**标准好零件的图**当模板，在其他图片里找"长得像的目标"，找到了就报出**位置（坐标）、角度、相似度**。

- 生活比喻：**通缉画像**——官府画个通缉犯画像贴城门口，来一个人比对一下，像的抓起来，不像放走
- 跟 [[01-卡尺工具Caliper]] 的关系：卡尺是**量尺寸**，模板匹配是**找位置/认目标**
- ⚠️ 默认模板是"正着比对"的，目标一歪就匹配不到 → 要设**旋转角**（见下文）

## 上软件前的准备

- **判断破解**：打开后双击 `CogJob1 Image Source` 进作业编辑器——有输入/输出/箭头=破解可用；显示的是一堆文字说没许可=没破解，需要下破解包（前提：先把软件关掉）
- **统一字号（汉化后字太小）**：右键软件 → 属性 → 兼容性 → 更改高DPI设置 → 勾最下面的"替代高DPI缩放行为" → 选"系统(增强)" → 确定确定。分辨率越大字越小，这样一步统一
- **素材摆放**：老师发的素材统一放一个文件夹保管，不要东放一个西放一个；微信登录好随时收文件

## 界面总览：QuickBuild

- 初始界面叫 **QuickBuild 未命名**："未命名"=还没保存过
- 顶上一排导航（文件/运行/配置/显示/帮助）一般不用，用**下一排按钮**：
  - **运行**：整个项目整体运行一次
  - **打开**：访问文件夹打开项目
  - **保存 / 另存为**：都是保存（保存方式有坑，见文末）
  - **添加工具**：创建新的工作/项目（CogJob1、CogJob2……）
  - **导入工具组**：一般用不到
  - **复位**：重置整个项目——参数输错连锁报错一大堆改不回来、又不想重开项目时，点它就当重新创建了
  - **连续运行**：不断反复运行

## 作业编辑器（双击 CogJob1 进入）

布局分**左右两半**：

- **右半边**是蓝色区域：专门用来**展示图片**——检测效果、图片长啥样都显示在这
- **左半边**从上到下：
  - 一排按钮：**运行**（只跑当前工具一次）、**本地显示/浮动显示**（显示/提取图片）、**复位**（只重置当前工具）、**连续运行**（多张图反复切）、**初始化图像来源**（打开 Image Source）、**实时画面**（没连相机点不了，接工业相机后就能看）、**配置作业属性**（一般不用）
  - **创建脚本**：通过写代码的方式让代码操控工具——手动拖100次工具 vs 代码里 for 循环跑100次，脚本完胜。之后会用到
  - 🔨 **工具箱**（锤子+扳手图标）：**全软件最重要、最值钱的部分**。里面一大堆工具，每个工具都有强大的功能，可以实现很多效果——之后主要就是学工具箱里的工具
- **Tool Group（工具组）**：放工具的地方。把工具拖到这儿，工具就进来了
- 里面自带一个 **Image Source**（图片资源/来源）工具

## Image Source：导入图片

双击主界面的 `Image Source`（或点编辑器里的"初始化图像来源"）会弹出图像来源界面：

- 切到"图像数据库"这一栏
- 两个导入按钮：
  - **选择文件**：导入**单张**图片
  - **选择文件夹**：一口气导入**多张**图片（有多张素材时用这个）
- 导入成功后**缩略图**里就有内容了；关掉 Image Source，运行作业编辑器，图片就显示出来，每次点击运行会**切换图片**

## 模板匹配工具 CogPMAlignTool

- 打开工具箱，**正数第9个**，叫 **CogPMAlignTool**（汉化名"模板匹配"）
- 加入 ToolGroup 的两种方式：**双击**自动加 / **按住左键拖拽**
- 获取目标的位置（坐标）只是它的其中一个功能，还能干很多别的事

## 连接图像（⚠️ 不连图工具读不到图片）

Image Source 上有个**输出**（output image），模板匹配工具上有个**输入**（input image）——**必须输出连输入**，工具才有图片可用。

- 三种连法：
  1. 点 `output image` 上的小箭头 → "连接" → 再点 `input image`
  2. 右键 `input image` → "连接" → 点 `output image`
  3. 鼠标左键按住直接拖
- ⚠️ **只能"输出→输入"方向连**，反过来（输入连输出）连不上

## 五步操作（重点，几乎80~90%都会用到）

1. **切换训练图像**：把图片上方的导览切到第二个"**训练**"
2. **点击抓取训练图像**：左侧训练参数界面点"抓取训练图像" → 图片回来，左上角多出**一个框 + 一个坐标轴**
3. **设置方框把目标框住**（像截图）
   - 框四角可拖大小；右侧可**旋转**；最下面可把框"清洗"成**平行四边形**（能调回来）
   - 框歪了调不回去？→ 切到"训练区域原点"栏：**选择=0、倾斜=0**，框就正回来了
4. **坐标轴放到方框正中心**：找不到正中心就点"**中心原点**"按钮自动对准
   - 为什么：坐标轴=匹配结果的**坐标点**放哪儿，结果点就在哪儿。放正中心一般就够用了
5. **点击训练**：工具把框住的小区域记下来当模板，之后就在其他图片里拿它做比对

五步做完 → **点击运行** → 灯变绿=运行成功不报错 → 看结果：把图片上方导览展开，切到 **Last Run → Input Image**，能看到匹配出的筐

## 运行参数

### 旋转角（目标歪了匹配不到的关键）

- 现象：正放的目标匹配到了，**歪的目标匹配不到**——电脑默认"正着比对"，不会变通，目标一有旋转它比对不上（"电脑比较笨"）
- 解决：切到"运行参数"栏 → 找"**角度**"
  - 默认用**左边固定值=0度**（汉化叫"标称值"）→ 所以只能正着匹配
  - 中间有个**小三角**，尖尖指向谁用谁 → 点它切到**右边"上线下线"**
  - 默认 ±45°；要覆盖各种角度就设成 **正负180** 或 **0~360**（一圈都能匹配）
- 案例：设 ±180 之后，各种角度的零件就都匹配到了

### 查找概数（漏匹配→调高）

- 现象：漏了几个目标没匹配上——"**查找概数**"太小（默认 1，找不了几个）
- 概数 = 大概查找的结果数量；目测图上有几个目标，填个**绝对够用**的值（案例填 30、50）
- ⚠️ 调高后能补全漏的，但也容易"**找过头**"（一个目标套好几个框）→ 用下面的阈值过滤

### 接受阈值（分数=相似度）

- 切到"**结果**"栏，看每个匹配框的**分数** = 相似度（1.000=100%）
- 相似度从高到低排；某处**断崖式下降**（82% 直接掉到 52%）= 从那儿往下的都是不合格框
- **红光框** = 匹配上了但分数比阈值低一丢丢的**警告**（"比阈值稍低，你要不要？"变红给你看）
- 默认阈值 **0.5**；调高 = 提高标准，低于它的全不要
- 设置原则：看结果分数，把阈值设在**想要的分界线上**（案例 0.75 = 只要 75% 相似以上）；别让最低合格分数紧贴阈值，防误杀

## 案例

### 案例1：连接件定位（演示）
- 框一个连接件做模板 → 训练 → 运行 → 切图看框和坐标 → 歪的匹配不到 → 设 ±180 → 全匹配
- 坐标点放目标圆圈中心时，匹配结果坐标只在目标位置出现

### 案例2：回形针（作业）
- 新建案例 → 导入回形针素材 → 挑一个回形针当模板（框歪了就把框**拉长放到位再旋转一下**套进去）→ 中心原点 → 训练 → 设旋转角 → 运行看效果

### 案例3：套环（演示）
- 挑**右下角**一个套环当模板，**小心翼翼**框起来（⚠️ 别把旁边的套环框进框里，会有误差）
- 中心原点 → 训练 → **先运行看有没有结果**，再调参数（别上来就调参数，防止一开始就调错）
- 匹配 3 个太少 → 概数填 50 → 带旋转的没匹配上 → 设 ±180 → 全出但找过头 → 看结果分数断崖（84% 直接掉 65%）→ 阈值设 **0.75** → **27 个结果全部正确**

## 保存项目（⚠️ 别白做）

- 保存项目**必须回到一开始的 QuickBuild 界面**点保存
- 工具界面里的"打开/保存"保存的是**工具配置/参数**，不是项目！之前有同学辛苦做完在工具里保存，结果打开闪退——保存错了
- 关闭时弹窗问是否保存：如果已经保存过就点"**是**"自动关闭；没保存点"否"= 啥都没了

## 作业布置

新建案例 → 导入回形针素材 → 挑其中一个回形针当模板 → 设置旋转角 → 运行试一下看效果

## 跟 OpenCvSharp / 卡尺的关系

- 对标 OpenCV **`Cv2.MatchTemplate`**：模板图在输入图上滑窗算相似度，找分数峰值的位置 = 目标位置
- OpenCV 原生**不支持旋转角度匹配**，要做多角度就得把图转多个角度分别 MatchTemplate（或用特征匹配 SIFT/ORB）
- 相似度分数对应归一化匹配系数（如 TM_CCORR_NORMED / TM_SQDIFF_NORMED）
- 与 [[01-卡尺工具Caliper]]：VisionPro 两个基础工具；机器视觉路线卡尺（测量）→ 模板匹配（定位）→ Blob
