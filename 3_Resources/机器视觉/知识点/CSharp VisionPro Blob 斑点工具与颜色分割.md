# C# VisionPro Blob 斑点工具 + 颜色分割 + 卡尺补充

8.26 下午的课，学了两个**全新的"计数类"工具**，还补了卡尺工具的折线图原理。重点是 **Blob（斑点）工具**——比模板匹配**更快更简单**地点出图片里的斑点数量（玻璃划痕、铁板油污、小孔洞等），以及 **颜色分割工具**（把指定颜色的区域单独割出来再数）。

> 📌 这课核心是**数"有几个"**（数量检测），Blob 工具两步搞定，模板匹配要四五步——**能用 Blob 就别用模板匹配数斑点**。老师最后还让把所有 VisionPro 工具按类别缕一遍（下一篇笔记），防止以后忘记。

## 🧩 卡尺补充①：看懂卡尺的折线图（投影数据）

上午测宽那个案例（iPhone 充电器 442），老师补讲卡尺下方的**第三张折线图**是怎么来的：

- 有**两条折线**：**投影数据** 和 **过滤的投影数据**
- **横坐标** = 扫描过程（从最左扫到最右，看成"扫描的时间"）
- **投影数据（第一条）**：纵坐标是**灰度值**（0 黑 ~ 255 白，共 256 个）
  - 扫描从白色背景进入物体 → 灰度**由白转黑瞬间陡降** → 这就是**第一个边缘**
  - 过完边缘进入物体内部（黑）→ 平稳一段 → 扫到另一头 → **由黑转白陡升** → **第二个边缘**
  - 所以灰度跳跃的地方 = 边缘
- **过滤的投影数据（第二条）**：纵坐标是**变换值**（灰度变化的剧烈程度）
  - 剧烈变化处会拱起一个小峰（变黑方向）或小鼓包（变白方向）→ **峰/鼓包的顶点 = 灰度变换最剧烈 = 边缘**
- 结论：**灰度跳变最剧烈的地方就是边缘**，投影数据帮你"看见"卡尺扫描的逻辑

## 🧩 卡尺补充②：三个让边缘认准的调参

当目标颜色和背景**差别不大**（比如灰色物体、灰背景）时，灰度变化不剧烈，可能把边缘认错。可调三个参数：

| 参数 | 作用 |
|---|---|
| **对比度阈值** | 边缘的灰度变化得超过这个值才算数（默认小）；调大 → 小波动（干扰峰/鼓包）不算边缘，只留真正的大峰/大鼓包 |
| **过滤一半像素** | 把折线上的**点过滤掉一半**（删掉中间一些点再连线），折线变**圆润** → 磨掉尖峰低谷，把真正的主峰单独拎出来 |
| **最大结果数** | 允许找**几个**边缘（默认 1）；调成 2 → 把刚才被对比度挡掉的那个小干扰峰也当边缘找出来 |

> **一句话**：只想留"真正的主边缘" → 调大**对比度阈值** + 过滤一半像素；想要更多小边缘/小斑点也算进 → 调大**最大结果数**。

## 🧩 卡尺补充③：扫描方向决定"测宽还是测高"（易错点）

- 想测**宽**：物体左右两边是边缘 → 卡尺要**上下扫描**（矩形转 90°，看**实心箭头**方向），让扫描线扫到上下两个边缘，求它们距离 = 宽度
- ⚠️ 很多人把矩形只覆盖目标就开始测——**不对**，扫描方向没对准，测的不是你要的。**先想清楚边缘在哪，让扫描方向垂直穿过那两个边缘**
- 上下扫 / 从哪头扫起都行，只要**扫描方向穿过你要测的两个边缘**即可（之前案例都是左右扫测宽，没做过上下扫测高，注意下）

## ✅ Blob 工具：比模板匹配快得多的"斑点计数"

**Blob（斑点）工具**图标 = 把背景上的一些小斑点**单独拎出来**。用来数"有几个斑点"超快，比如：

- 玻璃板上的油污、划痕数量
- 铁板上粘的杂质
- 图片里的黑圆点数量（某次作业：数黑斑，模板匹配挑了圆做模板）

### 使用步骤：就两步！

1. **设置极性**（最关键）：选**白底黑点**（白色背景、黑色斑点）或**黑底白点**（黑色背景、白色斑点）——看你的图"以什么为底、以什么为点"
2. **点击运行** → 查看结果（第四个图）→ 斑点数量出来了

> ⚠️ Blob 工具和模板匹配一样，**只支持灰度图**——彩色图要先**彩转灰**，转换别丢。

### 原理 & 参数

- **原理**：根据背景和斑点之间的**边缘极性**，自动把指定极性（形如白底黑点）的目标从背景中提出来
- **最小面积**：默认 10，**面积小于它的斑点自动忽略**——想漏掉小斑点，把最小面积调大（如案例里排除 1396 的小斑，设 1500）
- **高尾巴 / 低尾巴**：想找出不太明显的细微斑点，可调这两个参数，强行多筛/去掉一些内容

### 结果里会出现"孔（洞）"

- 结果里除了**斑点**，还可能有**孔**（类型列显示"孔"）
- **孔怎么来的**：你设为背景的部分，如果**斑点内部还夹着一小块背景色**（比如白点内部有个小黑洞），这块内部背景**不能再当背景**，会被单独列成"孔"（也算一种斑点）
- 一般的检测**不要孔**，只想留斑点 → 在**"测量尺寸"页**，把 `connectivity level`（类型）的运行设置改成**过滤** → 出现"低/高"范围 → **低0 高 0** 只排掉孔（孔=0，斑点=1）；要排斑点留孔就**低1 高1**；两个都不要就**低0 高1**

## ✅ 颜色分割工具 CogColorSegmenter2（把指定颜色单独割出来）

`Color` 文件夹里**最常用**的一个工具 = **颜色分割**：把图片里你想要的颜色区域**单独割出来**（其他颜色全变黑背景）。

- 打开后界面左右两半：**右半边**是图片，**左半边**是训练颜色的表格
- **新增**颜色有两种方式：
  - **选择点**：图片中心有个**十字准心**，准心移到哪个像素格，就取那个点的颜色 → 点"接受" → 颜色进表格
  - **选择区域**：给一个**方框**，取**整个区域内所有颜色的平均值**（一半红一半白 → 浅红；一半白一半黑 → 灰）→ 想取大一片的颜色用这个
- 可**分割一种或多种颜色**（点黄色、红色都加进去，两种胶囊一起出来）；想分开数就再拿**一个新的分割工具**单独数每种
- **红色会变绿的坑**：提取完红色，原图上红色会变成**记号色（绿）**提醒你提了啥 → 去"图形"页把"显示重叠的结果"去掉，图片就恢复原色

### 配 Blob 数胶囊数量

想数红色胶囊有几个：
1. **颜色分割**把红色区域割出来（输出的是**灰度分段图**，正好能给 Blob 用）
2. 接一个 **Blob 工具**，设**黑底白点**（分割后背景黑、红色区域变白斑）
3. 运行 → 红色胶囊数量出来了

## 🧠 一句话总结

1. **卡尺折线图**：投影数据纵坐标=灰度值、过滤投影=变换值；**灰度跳变最剧烈 = 边缘**
2. **卡尺三维参**：对比度阈值（大→滤小波动）、过滤一半像素（> →折线圆润磨尖峰）、最大结果数（大→找更多边缘）
3. **扫描方向**决定测宽还是测高：**穿透你要测的两个边缘**（测宽就矩形转 90° 上下扫）
4. **Blob 两步法**：设置极性（白底黑点/黑底白点）→ 运行；**最小面积**忽略小斑；**高/低尾巴**调细节；**孔**可用 connectivity level 过滤排掉
5. **颜色分割**：选择点（取像素色）/ 选择区域（取平均色）；割出的灰度分段图配 Blob 数数量

## 📚 作业 / 练习

1. **数黑斑**：彩色图 → 彩转灰 → 模板匹配挑一个圆做模板（缩放 0.1~2.5）→ 数出 12 个；再换成 Blob 工具两步法 → 更快
2. **玻璃划痕**：灰度图直接 Blob，设黑底白点 → 划痕明显比模板匹配找得多；小划痕用高/低尾巴调出
3. **孔排除**：把结果里的"孔"用 connectivity level 过滤掉，只剩斑点
4. **数胶囊**：颜色分割（选择点取红色）→ Blob 黑底白点 → 数红色胶囊数量；多颜色就多分割一个
