# C# VisionPro 测量与创建工具全家桶（找线 / 角度 / 距离 / 拟合 / 创建 / 相交 / 卡尺）

8.25 下午的课，VisionPro 视觉软件**从"识别"走向"测量"**：以**苹果充电器**（富士康出品的真实工业素材）为线，把找线、测角、测距、拟合、创建、相交、卡尺这些测量工具讲了个遍。

> 📌 这课信息量最大：**IDB 文件、找线、角度/距离测量、卡尺**是重点；Fit 拟合、Creation 创建、Intersection 相交是**拓展工具**（老师明确说"理解即可"，以后搭配脚本用）。
> 其中卡尺工具跟宝宝的[[视觉测量工具箱|VisionMeasureToolkit]]做的 Caliper 直接同源——概念完全通用！

## 🧩 素材：IDB 文件（图像数据库）

- 老师发的素材是个 **IDB** 文件（`Image DataBase` = **图像数据库**）
- 文件后缀名之一，视觉领域常见
- ⭐ **最关键是：单个 IDB 文件里存着多张图片**，是个"集合文件"
- 导入 VisionPro 运行后才看出有很多张图，但文件只有一个
- 以后看到 IDB 就知道：图片后缀 + 可能是一个图库

## ⚙️ 案例线：苹果充电器（富士康素材）

> 老师强调富士康做苹果充电器/屏幕/按键等配件，**靠视觉检测把关指标**。侧面要测**充电头与底座之间的角度**（歪了充不上电还易损坏）；正面要测**充电口的宽度**（宽了零点几毫米就插不进去）。

## 🧩 找线工具 Find Line（找角之前先找线）

- 要找"角"，得先找"角的两条边（线）"
- 工具位置：**Find → Fitting 文件夹 → 第 4 个 → Find Line Tool**
- 用法跟**上午讲的找圆（Find Circle）**类似，但不用设 360°：
  1. 你要找哪条线，就把找线卡尺**放到那条线上**
  2. 确保上面小矩形能**扫描到物体边缘**
  3. 运行 → 线找到了
- **找线原理**：卡尺扫描物体边缘 → 点几个点 → 画一条线；默认 6 个卡齿扫描 6 个点
- **让线更准的三种方法**：
  - **卡线数量调多**（比如 20 个卡齿 → 点 20 个点 → 画线更准）
  - **忽略点数**：把点得比较歪的点忽略掉，留准的点
  - **极性（急性/纪心）**：默认从左到右扫，灰度**由明到暗**是正边；设反了（暗到明）就扫不到线
- 💡 找线跟找圆一样，都要用**坐标定位**让它跟着目标自动测

## 🧩 找角工具 Corner（只是"找角"不是"测角"）

- **Find → 第 2 个 → Corner**（角的意思）
- 内部带**两个找线工具**，让两根线分别扫角的两条边，就能**找有没有这个角**
- ⚠️ 但它的**结果只有角的交点坐标，不给角度值**（终端里连角度参数都没有，展开不了）
- 结论：**Corner 只会"找角"，测不出角度** → 测角度要换工具

## 🧩 角度测量：CogAngleLineAngleTool（角-线工具）

- `Measurement` 文件夹 → **第 1 个 -> CogAngleLineAngleTool`（Angle 角 + Line 线）
- **作用：拿你已有的两根线，测它们之间的夹角**
- 用法：连接坐标定位后的图 → 需要两根线（Line A / Line B）→ 找线工具的**直线**输出连进去 → 运行
- 💡 为什么连**直线**不连线段：线段就那么长；直线可以无限延长，就算两根线没交汇，延长也交汇 → 测夹角用直线
- **弧度 vs 角度（坑）**：
  - 默认输出是**弧度**（如 -1.57 ≈ 90°，高中知识：弧度制）
  - 看不惯弧度 → 用**昨天讲的结果分析工具**按公式（角度 = 弧度 × 180 / π）换算成角度，再用文字工具展示
- 案例里测完角度 → 文字工具显示

## 🧩 Measurement 测量工具全家桶（"你要啥给啥"）

`Measurement` 文件夹一堆工具，**全是一个套路**：你要测啥，就给它准备啥输入（角→两条线；距离→两个圆/线/点…），运行就出结果。**会一两个，剩下全会**：

| 工具 | 作用 |
|---|---|
| Angle Line Line | **两线夹角** |
| Angle Point Point | **两点成线、与水平面的夹角**（按**顺时针**测） |
| Distance Circle Circle | **两圆之间的距离**（输入两个圆，圆由找圆工具来） |
| Distance Line Circle | 线到圆的距离 |
| Distance Line Ellipse | 线到椭圆的距离（椭圆用得不多） |
| Distance Point Circle | 点到圆的距离 |
| Distance Point Ellipse | 点到椭圆的距离 |
| Distance Point Line | **点到线的距离**（画垂线测）|
| Distance Point Point | 点到点的距离（不用手动算了）|
| Distance Point Segment | 点到线段的距离（⚠️跟点到直线**不一样**：直线是延长后做垂线；线段是直接算**最近距离**，不做垂线）|
| Distance Segment Circle | 线段到圆 |
| Distance Segment Ellipse | 线段到椭圆 |
| Distance Segment Line | 线段到直线 |
| Distance Segment Segment | 线段到线段 |

## 🧩 案例：连接键第二指标（点到线距离）

- 上午测了连接键**圆的半径**；连接键要连接两段东西，还得测**耳朵到圆心之间的距离**
- 流程：模板匹配 → 坐标定位 → 找圆（360°、找你要的圆、卡尺扫轮廓、忽略点数+极性由明到暗）→ 找线（连接键上边耳朵的线）→ **CogDistancePointLineTool**（Measurement 里**点到线距离**）
- 点到线工具：连图 → 输入点（找圆工具的 **CenterX / CenterY**）→ 输入线（耳朵线）→ 运行 → 距离就出来了（案例里 482 像素）
- 用文字工具显示「连接键的规格距离」

## 🧩 Fit 拟合工具（理解即可）

- **Find → 前四个是查找工具，剩下三个是 Fit（拟合）**：把散乱的**点**按趋势画一条线/一个圆
- 原理就是**最小二乘法**（高中知识）：取平均值画趋势线，不硬穿每个点
- 生活类比：地震波记录点 → 拟合趋势线看升降；炒股的 K 线/指数趋势
- **应用**：齿轮**缺了一块**也能测圆——把完好的那几个点拟合出圆轮廓，就测出半径了
- 用法：**有"你有啥给啥"**——拟合圆要连图 + **3 个点**（三个点才能确定一个圆，两个点圆的大小定不死）；拟合线（FitLine）至少 **2 个点**，可以多加输入点
- ⚠️ 一般用不到，**搭配脚本用**居多，理解即可

## 🧩 Creation 创建工具（创建圆/文字/线…）

`Creation`（创建）文件夹——**无到有创建图形**，当标记/展示用：

| 工具 | 作用 |
|---|---|
| 创建圆 | 检测一批产品时，用找工具把产品位置圈出来当**标记** |
| 创建文字 | （上上节讲过）图上动态显示文字 |
| 创建线 | 直接怼一条线 |
| **LineBasicPoints（中垂线）** | 两个点连线的中点做垂线（测量里会用） |
| **Parallel（平行线）** | 给一条基准线，创建它的平行线 |
| **Perpendicular（垂线）** | 给一条线 + 一个点，过点做线的垂线 |
| 创建线段 | 直接画一个线段 |
| **AVG Segment（等分线段）** | 把线段**等比例分割**成几段（两份/三份/四份…） |

> 老师：创建圆/文字/线/线段知道即可；垂线、平行线这些**一般用不到**，遇特殊情况再用，也多出现在**后续脚本**里。

## 🧩 Intersection 相交工具（判断几个交点）

`Intersection`（翻译：**相交/香蕉**）文件夹——判断图形**有没有交点（香蕉点）、有几个**：

| 工具 | 判断什么 |
|---|---|
| Circle Circle | 两圆交点（0 或 1 或 2 个）|
| Line Circle | 线与圆的交点 |
| Line Ellipse | 线与椭圆的交点 |
| Line Line | 两线交点（不平行就 1 个，平行就 0 个）|
| *(线到圆/椭圆/线)* | 依次类推 |

- **特殊的一个：Line Line（两线交点）** — 不仅告诉你交点，**还顺带测两线的夹角**（跟 Measurement 的角线工具效果一样）
- 适用场景：判断两个物体是否**重合**（比如两个齿轮叠一块）
- 用法跟 Measurement 一样：**你有啥给啥**
- 理解即可，以后讲脚本再带着用

## 🧩 卡尺工具 Caliper（测宽度，四步走）

充电器**正面**案例：要测**充电口的宽度**。

准备工作（跟找圆找线一样）：**先模板匹配 → 再坐标定位**——因为卡尺也得**跟着目标一块移动**去测。

- 卡尺界面跟找圆找线很像：
  - 右边图片上有个**矩形（卡尺）**，大小/旋转/倾斜都能调
  - **实心箭头** = **扫描方向**（从左往右扫）
  - **空心箭头** = 扫到边缘后**画线的方向**（从上往下画）

### 测宽度四步

1. **设卡尺大小**：把卡尺拉长，**确保能扫到目标两端（两侧）的边缘**
2. **边缘模式设为"边缘对"**：要测宽度 = 物体两端各画一根线（尺子量宽：零刻度对准一端，另一端读数值——两个值，所以是边缘对）
3. **设极性**：从左往右扫，**第一个边缘 由明到暗，第二个边缘 由暗到明**
4. **设量程**：卡尺下边有个**"边缘宽度"**代表尺子量程——默认 10 像素不够，**怼大点（1000 像素）**
5. 运行 → 查看结果 → 宽度出来了（案例里 **443.65 像素**），结果图能看到两端画了两根线

## 🧠 一句话总结

1. **IDB 文件** = 图像数据库，一个文件可能装多张图片
2. **找线 Find Line**：卡尺放线上扫边缘点成线；调**卡线数量 / 忽略点数 / 极性（明到暗）**让线更准；要跟着坐标定位走
3. **测角**：Corner 只能"找角"测不了角度 → 用 **Measurement 的角-线工具**（输入两根线），小心**弧度 vs 角度**（默认弧度，可经结果分析工具换算）
4. **Measurement 全家桶**："你要啥给啥"——两点测夹角、两圆测距、**点到线做垂线**、**点到线段算最近距离（不做垂线）**…
5. **Fit 拟合** = 最小二乘法，散点画趋势线/圆，齿轮缺块也能测；**三点定圆、两点定线**
6. **Creation 创建**：创建圆/文字/线/中垂线/平行线/垂线/等分线段——当标记用
7. **Intersection 相交**：判断图形有几个交点；**两线相交还顺带测夹角**
8. **卡尺 Caliper 测宽四步**：卡尺拉长扫两端 → 边缘**对** → 两极性（明→暗 / 暗→明）→ 量程怼大 → 运行得宽度

## 📚 作业

1. 苹果充电器侧面：模板匹配 + 坐标定位 → 找线 → **角-线工具**测角度，用结果分析工具把弧度换角度 + 文字工具显示
2. 连接键第二指标：找圆（CenterX/Y）+ 找线（耳朵）→ **点到线距离**工具 → 文字工具显示（482 像素那个）
3. 充电器正面：模板匹配 + 坐标定位 → 卡尺四步测**充电口宽度**（边缘对 + 极性 + 量程 1000）
4. 拓展工具（Fit / Creation / Intersection）：读懂每个是干啥的，知道去哪找就行
