> 📌 **软件常识**：VisionPro 是**美国康耐视（Cognex）公司**的视觉软件。凡是**`cog` 开头的工具**都是康耐视的东西——**`cog` = 康耐视的简写**（类似商标/logo），看到 cog 开头多半就是康耐视的组件。

## 🗂️ 四类工具速览

| 类别 | 干啥 | 代表工具 |
|---|---|---|
| **查找（Find）** | 找到目标位置/数量 | 模板匹配、找圆、找线、找角、Fit 拟合 |
| **创建（Create）** | 无到有造图形 | 创建圆/线/线段/文字、中垂线、平行线、垂线、等分线段 |
| **相交（Intersection）** | 判断有没有交点/几个 | 圆圆、线圆、线线 |
| **测量（Measurement）** | 算角度/距离 | 角-线测角、点到线/圆/点距离 |

## 🔤 一、软件基础 & 图像输入

- **VisionPro** = 康耐视公司的视觉软件
- **颜色资源（图片资源）工具**：用于**导入图像**——导入本地图片，或**接工业相机**
- 名词约定：**cog** 开头 = 康耐视组件

## 🔍 二、模板匹配 & 进阶

- **模板匹配工具（CogPM 开头）**：匹配目标的**位置**和**数量**
- 内部有两个进阶应用——**眼膜（Mask）** 和 **剑膜（训练模型）**：
  - **眼膜** = 把**不需要的特征掩盖掉**
  - **剑膜** = 建立**需要的特征**模型
  - 二者都能把需要的内容留下、不需要的去掉，**都能增强匹配程度**
  - 关键：**分清眼膜（掩盖）和剑膜（建需要的模型）**

## 🔤 三、文字 / 彩转灰 / 结果分析

- **文字工具（Cog Graphic Label）**：展示文字，或**动态展示工具的结果数据**
- **彩转灰工具（Cog Convert）**：把**彩色图转灰度图**（因为模板匹配、Blob 等只认灰度图）
- **结果分析工具（Cog Analyze）**：**计算一些数据**（如数量×面值 = 金额）

## 📐 四、测量之前必须做：坐标定位

- **坐标定位工具**：**重新建立坐标**，把坐标**原点设置到模板匹配的中心原点**上
- 之后的找线、找圆、测量都要**基于它**（连\"定位后的图\"），才能跟着目标移动

## 🎯 五、Find 查找类工具

**四个找工具**（加引号的\"找角\"只能找角、没有角度）：

1. **找圆工具**：找到圆（360°扫描、卡尺扫轮廓）
2. **找角工具（\"找角\"）**：只是找角，**不给角度值**
3. **找椭圆工具**：找椭圆
4. **找线工具**：找直线

**Fit 拟合类工具**（把散点按趋势画线/圆，最小二乘法）：
- **拟合圆工具**（三点定圆）
- **拟合椭圆工具**
- **拟合线工具**（两点定线，可加更多点）

## ✍️ 六、Create 创建类工具

**四个基本创建：**
- **创建圆**（Cog Create Circle）
- **创建线**（Cog Create Line）
- **创建线段**（Cog Create Segment）
- **创建文字**（在前面讲过）

**三个特殊创建：**
- **中垂线**（Cog Create Line Basic Points）：创建**两点之间的中垂线**
- **平行线**（Cog Create Line Parallel）：根据一条线，**创建它的平行线**
- **垂线**（Cog Create Line Perpendicular）：根据**一条线 + 一个点**，创建过点的垂线
- **等分线段**（Cog Create Segment AVG）：把一个线段**平均分成多段相同长度**

## ⭕ 七、Intersection 相交类工具

判断两图形**是否相交、有几个交点**：
- **圆-圆相交**（判断两个圆是否相交、几个交点）
- **直线-圆相交**（一圆一线，判断相交、几个交点）
- **直线-直线相交**（两线交点）

## 📏 八、Measurement 测量类工具（你有啥给啥）

**角度类：**
- **角-线工具（Cog Angle Line Line）**：测量**两条直线之间的夹角**
- **角-点工具（Cog Angle Point Point）**：两个点连成线，测**这条线和水平面的夹角**

**距离类（全套排列组合）：**
- **直线-圆距离**（Cog Distance Line Circle）
- **圆-圆距离**（Cog Distance Circle Circle）
- **直线-椭圆距离**（Cog Distance Line Ellipse）
- **点-圆距离**、**点-线距离**、**点-点距离**、**点-椭圆距离**
- **线段-圆/椭圆/线/线段距离**（线段相关，算最近距离不做垂线）

> 类型看着多，但**用法全类似**（\"你要啥给啥\"），只是**输入排列组合多**而已——**会一两个，剩下全会**。

## 🧠 一句话总结

1. **VisionPro = 康耐视公司的视觉软件**，`cog` 开头 = 康耐视组件
2. 工具分**四大类**：**Find 查找** / **Create 创建** / **Intersection 相交** / **Measurement 测量**
3. **测量前必须坐标定位**（原点设到模板匹配中心）
4. **眼膜（掩盖不要的）vs 剑膜（建需要的模型）要分清**
5. **Measurement 距离/角度工具**就是一堆排列组合，**\"你有啥给啥\"**，套路统一
