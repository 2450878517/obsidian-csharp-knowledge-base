# C# VisionPro 多模板匹配与标定板工具（9.7上午）

本节分成两部分：先用 `CogPMAlignMultiTool` 把多个模板放进同一个多模板匹配工具，解决硬币多类别或同一目标多角度匹配的问题；再用 `CogCalibCheckerBoardTool` 做标定板标定，把像素坐标转换为真实尺寸，并利用多张标定板图像校正镜头畸变。

学习路线：上午先掌握多模板匹配、标定和真实尺寸测量；下午再把模板匹配、几何测量和坐标换算组合成表盘读时案例。

## 一、CogPMAlignMultiTool 多模板匹配

### 1. 为什么需要多模板

普通 `CogPMAlignTool` 一次主要训练一个模板。之前的硬币案例需要分别创建多个模板匹配工具，例如：

- 一个模板匹配一元硬币。
- 一个模板匹配五角硬币。
- 一个模板匹配一角硬币。

如果把这三个工具合并，或者同一个目标需要从多个角度训练多个外观，普通模板匹配会比较笨重。`CogPMAlignMultiTool` 可以在一个工具中保存多个 Pattern，再统一运行匹配。

```csharp
CogPMAlignMultiTool multi =
    mToolBlock.Tools["CogPMAlignMultiTool1"]
    as CogPMAlignMultiTool;
```

实际工具名称要以 ToolBlock 中的名称为准。这个工具适合：

- 同一张图里有多种目标，需要统一匹配。
- 同一个目标会以正面、侧面、旋转等多种姿态出现。
- 不想为每一个模板单独创建一个 PMAlign 工具。

### 2. 创建多个 Pattern

把 `CogPMAlignMultiTool` 拖进 ToolBlock 后，进入工具界面。主体是一个 Pattern 表格，操作顺序是：

1. 点击 `Add Pattern` 新增一个模板。
2. 双击这一行的 `Edit`，进入该 Pattern 的模板匹配界面。
3. 抓取训练图像，设置训练区域和原点。
4. 训练模板；需要时使用掩膜遮掉不稳定或会干扰的区域。
5. 重新训练，确认结果后关闭编辑界面。
6. 重复添加 Pattern，分别训练一元、五角、一角，或同一目标的多个角度。

多模板工具里的单个 Pattern 主要负责模板训练，不要把它当成完整的独立 PMAlign 工具来调所有运行参数。训练完成后，表格中会出现训练完成的标记。

### 3. 启用模板并设置整体参数

模板训练完成不等于运行时一定使用它。还要在表格的使用状态中启用对应 Pattern，然后切换到多模板参数页面，把要使用的模板加入右侧的使用列表。

整体运行参数由多模板工具统一控制，课堂重点提到：

- 查找数量：是所有已启用模板的匹配结果总数的大致上限，不是某一个模板单独的数量。
- 接受阈值：统一控制匹配结果的最低相似度。
- 旋转角：统一控制这些模板允许的旋转范围。

例如三种硬币总数大约为 10 个，查找数量设置为略大于总数量的值即可。设置完成后运行工具，结果中会同时出现不同硬币的匹配结果。

### 4. 多模板和普通模板的区别

普通 PMAlign 更像“一张模板找一种外观”；多模板 PMAlign 则是“一组模板找多种外观”。例如要匹配一辆汽车：只训练正面模板时，侧面汽车可能匹配不到；把正面、侧面和其他角度分别加入 Pattern 后，工具可以根据目标当前的外观进行匹配。

不要为了省事把差异很大的目标硬塞进同一个模板。多模板的前提是每个 Pattern 都有清楚、稳定、能区分目标的训练区域。

## 二、CogCalibCheckerBoardTool 标定板工具

### 1. 标定解决什么问题

普通图像测量得到的是像素距离，例如两点相差 100 个像素。生产检测更关心毫米、微米等真实尺寸，所以需要建立“图像像素 ↔ 实际长度”的比例尺。

标定板上每个格子的实际尺寸是已知的。工具识别出格子在图像中的像素间距后，就能建立一套坐标和比例关系。标定完成后，在校正后的图像上测量，结果可以直接换算为真实尺寸。

标定通常发生在相机、镜头、光源和安装位置固定之后：

- 先把相机高度和角度调好。
- 调好光源，使目标轮廓清晰。
- 相机固定后放入标定板拍照。
- 标定完成后再进行实际尺寸测量。

如果相机、镜头或工作距离发生明显变化，应重新检查甚至重新标定。

### 2. 工具位置和输入要求

在 VisionPro 工具箱的 `Calibration & Fixturing` 分类中，课堂使用的是：

```text
CogCalibCheckerBoardTool
```

它不是普通的图像增强工具，而是用于建立校正坐标和比例尺的标定工具。课堂素材是彩色图像，直接连接到标定板工具时会提示不支持该操作。

因此要先用 `CogImageConvertTool` 把输入图像转为灰度，再连接到标定板工具：

```text
Image Source
    ↓
CogImageConvertTool       （彩色转灰度）
    ↓
CogCalibCheckerBoardTool
```

### 3. 选择标定板类型

进入工具后，界面主要分为校正模式、标定板设置和结果区域。先在标定板的特征搜索器中选择实际使用的板型。

课堂棋盘格素材选择普通 `Checkerboard`。常见板型包括：

- 棋盘格。
- 点网格。
- 详尽棋盘格。

详尽棋盘格是在普通棋盘格基础上增加更多标记和数据的板型。选择必须和实际标定板一致，不能因为名称相似就随便套用。

### 4. 设置基准符号

基准符号用于帮助工具确定标定板的方向、位置或唯一身份。课堂列出的选项有：

```text
None
StandardRectangle
DataMatrix
dataMatrixWithGrdPitch
DoGridAxes
```

它们可以理解为：

- `None`：标定板没有额外基准符号。
- `StandardRectangle`：标定板上有矩形标记。
- `DataMatrix`：标定板上有二维 Data Matrix 标记。
- `dataMatrixWithGrdPitch`：在二维标记基础上还带有网格间距信息。
- `DoGridAxes`：使用棋盘格自身的网格轴作为基准。

课堂使用的普通棋盘格没有额外基准符号，所以选择 `None`。不同 VisionPro 版本的界面拼写可能略有差异，以本机下拉框为准。

### 5. 设置格子尺寸

`Block Size` 表示标定板每个格子的真实尺寸，单位通常是毫米。例如：

- 每格 1 mm，就填 1。
- 每格 2 mm，就填 2。
- 每格 3 mm，就填 3。

这个值必须按标定板的实际规格填写。填错格子尺寸，工具仍可能计算出校正结果，但后面的真实尺寸会整体按错误比例缩放。

### 6. 抓取图像并计算校正

单张棋盘格图像的基本流程是：

1. 导入标定板图像。
2. 转换为灰度图。
3. 选择正确的棋盘格类型。
4. 设置基准符号。
5. 填写 `Block Size` 实际尺寸。
6. 点击 `Grab Calibration Image`，抓取校正图像。
7. 点击 `Compute Calibration`，计算校正。
8. 运行工具，查看识别出的棋盘格、校正点和坐标空间。

计算成功后，工具会输出校正后的图像和对应坐标关系。回到作业编辑器时，输出图像就是经过标定处理的图像，后续测量应连接这张输出图像。

## 三、标定后的实际测量

标定完成后，可以把输入图像切换成之前的实际案例，例如充电器素材。标定板的图像可以移除，但工具已经保存了计算出的标定信息。

将实际目标接到标定工具，运行后使用标定后的输出图像进行测量，测量结果会从像素距离换算成实际规格。课堂中充电器示例测得约 `7.11`，这个数值只属于课堂素材，不能当作通用结果。

```text
原始图像
    ↓
标定板建立比例尺和坐标关系
    ↓
校正后的输出图像
    ↓
在输出图像上测量
    ↓
得到毫米等实际单位
```

在 Visual Studio 中可以记录工具类型：

```text
CogCalibCheckerBoardTool
```

它的第一项核心作用就是建立图像像素和实际规格之间的比例尺，让后续测量直接得到真实尺寸，而不是像素值。

## 四、用多张标定板图像消除畸变

### 1. 为什么要多张图

真实镜头可能存在畸变，单张标定板图像只能提供一个位置和姿态下的信息。为了估计整个视野中的畸变，可以使用同一块标定板，在不同位置、不同方向拍摄多张图像。

操作方式是：

- 第一张图点击 `Grab Calibration Image`。
- 换到另一位置或方向，再点击一次 `Grab Calibration Image`。
- 继续添加多张标定板图像。
- 所有图像都抓取完成后，最后统一点击 `Compute Calibration`。

课堂用“假设 10 张图像”说明：前 9 张只负责不断加入校正图像，最后一张加入后再计算一次。工具会综合这些姿态和位置，估计视野中的畸变并生成校正结果。

### 2. 两类常见畸变

#### 镜像畸变 / 径向畸变

镜头和光学系统会使原本的直线发生弯曲，常见表现是：

- 桶形畸变：原本的矩形向外鼓，左右边缘像桶一样向外凸。
- 枕形畸变：原本的矩形向内凹，边缘像枕头一样收进去。

这类畸变主要与镜头光学和光线折射有关。

#### 切向畸变 / 透视畸变

相机镜头没有和目标保持平行，或者安装角度有倾斜时，会出现透视变化：

- 近处看起来大，远处看起来小。
- 原本的矩形变成梯形或带明显倾斜的形状。
- 目标产生“近大远小”的立体感。

使用同一标定板在不同方向、不同区域采集图像，可以帮助工具估计这种变化，并在计算校正时将其消除。

## 五、两个工具的组合思路

```text
多模板匹配：解决“目标外观有多个模板”
        ↓
标定板工具：解决“像素距离如何变成真实尺寸”
        ↓
标定输出图像
        ↓
PMAlign / Blob / Caliper / FindLine 等工具
        ↓
在真实单位下完成测量
```

多模板匹配关注“找到谁”；标定板关注“找到的距离到底是多少”。它们可以组合到同一个视觉项目里，但职责不同，不要把模板匹配结果数量当成标定结果。

## 六、常见坏人

- 多模板工具只训练了 Pattern，却没有把它启用到使用列表：运行时不会使用它。
- 把多模板运行参数理解成单个模板参数：查找数量、阈值和旋转角通常是整体参数。
- 用彩色图直接连接标定板工具：先转灰度。
- `Block Size` 随便填写：必须使用标定板的真实格子尺寸和正确单位。
- 选择错误的棋盘格类型：板型必须和实际标定板一致。
- 有基准符号却选择 `None`，或没有基准符号却选择了 Data Matrix：根据板面实际标记选择。
- 每张标定板图像都点击 `Compute Calibration`：多张图应先逐张抓取，最后统一计算。
- 相机移动后继续使用旧标定结果：相机高度、角度、镜头或工作距离明显改变时要重新检查。
- 把桶形、枕形和透视变化混成一种畸变：前两者主要是径向畸变，后者主要是切向/透视畸变。
- 把课堂中的 `7.11` 当成固定答案：它只对应课堂充电器素材和当时的标定板。

## 七、复习练习

- 用三种硬币训练三个 Pattern，比较普通三个 PMAlign 和一个 `CogPMAlignMultiTool` 的结构差异。
- 给同一个目标准备正面、侧面和旋转后的多张模板，观察多模板匹配的适用场景。
- 用一张棋盘格图完成灰度转换、棋盘格类型、`None` 基准符号、格子尺寸和校正计算。
- 再加入不同位置、不同方向的标定板图像，最后统一计算校正。
- 在标定输出图像上接一个距离测量工具，检查结果是否从像素变成毫米。
