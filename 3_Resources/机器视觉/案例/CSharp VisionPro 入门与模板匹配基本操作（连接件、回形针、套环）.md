# C# VisionPro 入门与模板匹配基本操作（连接件 / 回形针 / 套环）

8.24 上午的课，正式进入**康耐视视觉软件 VisionPro** 的第一次实操课：先认识软件、装好能跑，然后讲最核心的**模板匹配基本操作**，用**连接件 / 回形针 / 套环**三个案例练手。

> 📌 视觉软件课的开端。**模板匹配（CogPMAlign）基本五步 + 三个参数（旋转角 / 覆盖数 / 阈值）**是后面所有视觉课的基石——下午的齿轮检测、硬币、测量全靠它。

## 🧩 准备工作（装好软件先干这两件事）

### 1. 判断软件能不能用（破解了没）
- 软件是**破解 + 汉化**的，打开可能略卡两三秒，正常
- 双击 **cogjob1** 进作业编辑器：如果**有输入、有输出、有箭头有内容** → 破解成功能用
- 如果显示一堆"没有许可"的文字 → **没破解**，要把软件**关掉**，再用老师发的破解软件破解
- ⚠️ 破解时**务必先关掉 VisionPro**（开着破解不了）

### 2. 统一字体大小（高 DPI 缩放）
- 汉化破解后，字体随电脑**分辨率**变动：分辨率大字小、小吃大
- 调整：**右键软件 → 属性 → 兼容性 → 更改高 DPI 设置 → 勾\"替代高DPI缩放行为\" → 选\"系统(增强)\"** → 确定
- 最大就只能这样，不能再放大了

## 🧩 认识 VisionPro 软件

- 康耐视（Cognex，美国公司）出的视觉软件，功能强大，全球很多公司用；除了它还有 Halcon / VisionMaster 等——**VisionPro 综合性好、适合入门**
- 打开后叫 **QuickBuild 未命名**界面（因为没保存）；主界面下有很多导航栏（文件/运行/配置…），**一般不用导航栏，用的是下一行按钮**

### 快捷按钮（QuickBuild 界面）
| 按钮 | 作用 |
|---|---|
| 运行 | 运行整个项目一次 |
| 打开 | 从文件夹打开已保存的项目 |
| 保存 / 另存为 | **保存项目** |
| 添加 cogjob | 创建项目/工作（项目一/二/三…）|
| 导入工具组 | 一般用不到 |
| 复位 | **重置整个项目**（参数输错连锁报错，不想重开就直接复位）|
| 连续运行 | 不断运行 |

> ⚠️ **保存项目的大坑**：**一定要在最开始的 QuickBuild 界面点保存**！（工具界面里的"保存"只保存**工具配置**，不是整个项目——有人做完项目只保存了工具，结果打不开白做。）

### 作业编辑器布局（双击 cogjob1 进入）
- **右半边**：蓝色区域 = **展示图片**（检测效果、图片长啥样都在这）
- **左半边**：上面同样是导航栏（用按钮不用它）；下一行按钮：
  | 按钮 | 作用 |
  |---|---|
  | 运行 | 运行 cogjob1 一次 + 有图可**切图** |
  | 本地显示 / 浮动显示 | 显示图片的开关 |
  | 复位 | 把 cogjob1 重置到刚打开的空状态 |
  | 连续运行 | 多图时不断反复运行 |
  | 初始化图像来源 | 弹出图像来源界面 |
  | 实时画面 | 连了工业相机才能看（没连就点不了）|
  | 创建脚本 | 写代码操控工具（以后会用到）|
  | **工具箱（锤子扳手图标）** | **整个软件里最值钱最重要的内容**，一堆强大的工具 |
- **Tool Group（工具组）**：作业编辑器的主体，**放工具的地方**（把工具箱的工具拖进来就出现在这）

### 工具箱（精髓所在）
- 点了弹出工具箱界面，**一堆工具**，每个都能实现很多效果，**我们之后就是要学工具箱里的工具**

## 🧩 图片导入（Image Source 图像来源）

- 双击 **ImageSource**（或点"初始化图像来源"）弹出图像来源界面，切到**图像数据库**栏：
  - **选择文件**：单张导入图片
  - **选择文件夹**：多张图片一口气全导入
- 导入成功后**缩略图**里有内容 → 关掉 ImageSource，运行作业编辑器 → 图片出来，点运行可**切图**切换
- ⚠️ 素材要**统一放一个文件夹**保管，别东放一个西放一个（老师会发很多素材）

## 🔗 工具怎么连接图片（三种方式）

工具要操作图片**必须连接图片**。看图 Group 里工具下的小箭头：**箭头向左=输入，向右=输出**。
- ImageSource 只有**图片输出**；工具（模板匹配）有一个**输入图片** + 五个**输出结果**
- 把 ImageSource 的 **output image** 连到工具的 **input image**：
  1. **右键输出 → 连接到 → 选输入**（自动匹配可连的）
  2. **右键输入 → 连接字（谁可以连我）→ 选上面的输出**（反向连）
  3. **鼠标左键按住不松直接拖拽**（⚠️ 拖拽只能**输出连输入**，输入连输出连不上）

## 🧩 模板匹配工具 CogPMAlign（获取目标位置）

- 工具箱里**正数第 9 个**（`CogPMAlign`）就是模板匹配工具
- **作用**：获取目标物体位置（这只是它一个功能，还能干很多事）
- 拖拽进 Tool Group（**双击自动加入** / **左键拖着**）；拖多了就选中右键**删掉**
- 工具界面：同样左右两半，右展示图；上边有 运行 / 小闪电（暂不讲）/ 显示图控件 / 打开保存（**这里是保存工具配置，不是项目**）/ 复位
- 下边可切换：**训练参数 / 训练区域与远点 / 运行参数 / 搜索结果**

## ⭐ 模板匹配基本操作（五步，超关键！）

> 模板匹配原理（老师打的比方）：**像古代官府画通缉令**——把目标的样貌"记下来"，到城门（其他图片）对比，像的就框住。工具先把框住的模板**记住**，再去其他图片比对。以后**百分之八九十**都会用到它。

1. **切到 TrainImage（训练图像）**：图片上边导航栏切到第 2 个（寸隐媚者=TrainImage，训练的意思）。里面什么都没是正常的（还没训练过）
2. **抓取训练图像**：左半边训练参数里点「抓取训练图像」→ 图片回来，左上角多了**一个框 + 一个坐标轴**
3. **设置方框**：把目标**框住**（像截图）；框能拉四角调大小、能旋转、能调成平行四边形（清洗）；框歪了调不正就到「训练区域与远点」里把**选择/倾斜设回 0**
4. **把坐标轴放方框的正中心**：坐标轴就是结果要输出的那个点的位置；有强迫症找不到中心 → 「训练区域与远点」里点**中心远点**自动对准
5. **点击训练**：工具把框的内容存进"模式"，之后运行就以它为基础去其他图比对

### 结果怎么看
- 运行 → 图片上边导航栏切到 **Last Run** → 匹配到的目标被**框住**
- 匹配到的框**正中心有个点** → 鼠标放上去有坐标 = 这个目标的坐标（坐标轴放哪，结果点的坐标就在哪测）

### ⚠️ 三个关键参数（运行参数里调）

| 参数 | 作用 | 怎么调 |
|---|---|---|
| **旋转角（角度）** | 模板按固定角度找还是按范围转着找 | 默认"标称值/固定值"0度（只找正着的）；切到右侧**上下限**（点中间小三角，尖指哪用哪），**±180 或 0~360** 即可转着找到任意角度目标 |
| **查找覆盖数（概数）** | 一次性匹配多少个结果 | 默认 1 → 会漏；**目测图里大概多少个就填多少**（回形针三四十个填 30、套环填 50），填个足够大的 |
| **接受阈值（预值）** | 相似度低于这个就排除 | 默认 0.5；看结果分数调到 **0.7~0.8**（案例取 0.75），把低分假框排掉 |

### 分数 = 相似度（结果看这里）
- 切到 **结果** 栏：每个框有一堆结果（XY、角度…），重要的是**分数**（相似度）
- 由高到低排：前几个 90%/80%+ 都正常；**突然掉到 50%** 那些就是**不像的（假框/找过头）**
- 鼠标点某个分数，对应框就显出来——**80%以上是真目标，50%那些全不对**

### 找过头 / 红框是什么
- **查覆盖数调太大**会**找过头**（一个目标好几框 / 红框乱标）——找过头能排，比漏掉好
- **红框** = 分数比阈值**低一点点**的警告框（工具不棒子打死，只是标记让你判断要不要）；把阈值调高一点（0.75）就把这些**低分假框排掉**

> 温馨提示：**先确保工具能正常运行，再根据结果调参数**——别一上来就调参数，容易一开始就调错。

## 🧩 案例实战 ×3

### 案例 1：连接件定位
- 导入连接件素材 → 用上面五步框一个连接件 → 训练 → 运行
- 一开始**正着的匹配到、歪的匹配不到**（电脑默认不会转着找）→ 设**旋转角 ±180** → 歪的也全匹配到了

### 案例 2：回形针（数回形针）
- 挑一个回形针框起来当模板（**别框到旁边的**，有误差）→ 训练 → 运行
- 只匹配 1 个 → **覆盖数设 30**（图里大概三四十个）→ 都匹配到了但**找过头**
- 看结果分数：80%+ 是真的，突然掉 50% 全不对 → **阈值设 0.75** → 排掉假框 → **13 个**（表格从 ID0 到 12）

### 案例 3：套环
- 套环基本都挨一块，**挑右下角单独那个**，小心框起来（别把旁边套环框进来）→ 训练 → 运行
- 只匹配 3 个 → **覆盖数设 50**，**旋转角 ±180** → 都匹配到了但找过头
- 看分数：87%、84% 能接受，**84 突然跳到 65**（0.652、0.627、0.603）都不对 → **阈值设 0.75**（或 0.8）→ **27 个结果**，每个套环都套上了

## 🧠 一句话总结

1. 装好能用：先判断**破解**（作业编辑器有输入输出），再调**高DPI缩放**统一字体
2. 界面：QuickBuild（保存项目在这！）→ 作业编辑器（Tool Group 放工具）/ 工具箱（精髓）
3. 连接图：三种方式，拖拽只能**输出连输入**；工具不连图读不到图片
4. **模板匹配五步**：切TrainImage → 抓取训练图像 → 框目标 → 坐标放框中心（中心远点对齐）→ 训练 → 运行
5. **调参别一上来就调**：先确保能运行，再按结果调——**旋转角 ±180**（找任意角度）、**覆盖数目测够大**、**阈值按分数调 0.7~0.8**（排掉低分假框）
6. **分数=相似度**：突然暴跌的那些就是找过头的假框；红框是低预值警告

## 📚 作业

1. 连接件案例：五步框模板 + 旋转角 ±180 → 各个角度的连接件都能匹配到
2. 用回形针素材：挑一个当模板 + 旋转角 → 覆盖数目测设够 → 看分数调阈值，把找过头的假框排除
3. 套环案例（自己练一遍）：挑右下角单独套环当模板 → 五步 → 覆盖数 50 + 旋转角 ±180 → 阈值排掉低分 → 27 个套上
4. 做完记得**退回 QuickBuild 界面点保存**（关闭时弹窗问是否保存**点"是"**，别点"否"全没了）
