# C# VisionPro 综合测量案例（钻头 + 火花塞，工具串起来用）

8.26 上午的课，**不学新工具**，把前面学的模板匹配、坐标定位、找线、测角、垂线、交点、点到线距离**串成一个完整测量案例**——练"整个测量流程怎么做"。素材是**钻头**（圆柱形工件）和**火花塞**（带螺纹的金属零件）。

> 📌 这节课重点不是某个工具，而是**整套流程的先后顺序**和**连线方式**——两个案例都是"模板匹配 → 坐标定位 → 找线/找点 → 各种距离角度测量"。老师反复强调：**多动手自己连一遍**，比看老师做十遍都管用。

## 🎯 为什么要先"坐标定位"（贯穿全课的错误点）

**"坐标定位"（Coordinate Setup）工具是整套测量的地基**，两个案例全用它，也是最大坑点：

- 它的作用：把原本**图片左上角**的零零点，**重新定位到目标物体的中心点上**（比如钻头中心 / 火花塞中心）
- 定位之后，**只看原点变了，坐标数值不变**——但后续一切工具只要连的是"定位后的图"，找出来的坐标就会**跟着目标一块移动**
- 所以流程永远是：**先整体模板匹配 → 再坐标定位 → 之后才找线/找点/测量**

### 坑：模板匹配连"原图"还是"定位后的图"？

- ✅ 正确：模板匹配连的是**坐标定位后的图**（经过坐标换算的）
- ❌ 错误（绝大多数同学的错法）：模板匹配连了**原图**，但线、测量工具连的是定位后的图
- 后果：点没经过坐标定位，线经过了——**你以为测的是点到线的距离，实际测的是点到"另一条线"的距离**，结果对不上

> **一句话记住**：既然要测量，**找线、找点、测量所有工具都要连"定位后的图"**，不要有的连原图有的连定位图。

## ⚙️ 案例一：钻头检测（三个指标）

钻头 = 圆柱形工件，要测三个东西：

### 指标① 钻头尖的角度

- **第一步**：整体模板匹配（框钻头轮廓 → 中心圆点 → 训练）→ 坐标定位 → 别忘了设**旋转角**
- **第二步**：找两根线（钻头尖的两条边）——卡尺放在边上，**卡尺数量调多点**让线更准
- **第三步**：用 **Measurement → Angle Line Line（角线工具）** 连两根线 → 运行 → 角度出来了

### ⚠️ 钻头尖角度的坑（共性错误）

很多同学找的角"不太对"——找到的是**平角**或**对角**：

- 原因：**手动操纵工具时，电脑不知道你要找哪个角**，找线时的方向不确定，角就匹配得随意
- 线的角度本质：一根线作为 0°，**逆时针旋转多少就是它的旋转角**（如线A -179° ≈ 逆时针转了 180°；线B -89° ≈ 逆时针 90°；-180° 到 -90° 之间转了个正 89° ≈ 测出来的就是它）
- 解决：**手动操纵只能找"对/平/对角"这些情况**；要精确画指定角，**得等后面讲脚本/代码**——脚本能确定线的方向，想找哪个角就找哪个角

### 指标② 钻头尖尖到底座的距离

- 底座：找线时**多设卡尺**，即使线有点歪也能把底座线完整测出来
- 尖尖的点：**用模板匹配匹配尖尖**（连定位后的图）
- 距离：**Measurement → Distance Point Line（点到线距离）**——需要一点（模板匹配中心点）+ 一线（底座线）→ 运行 → 距离出来了
- 再次强调 ⚠️：**匹配尖尖的模板匹配必须连"定位后的图"**，不然点和线坐标不同源，测出来的是另一个距离（就是指标①②之间那个共性错误）

## ⚙️ 案例二：火花塞检测（三个指标）

火花塞 = 带螺纹的金属零件，要求测三个值：

### 统一的开头：模板匹配 → 坐标定位

- 既然要测量，**难免要找线找点找圆** → 先做一次**整体模板匹配**，再把**坐标定位**定位好
- 定位完，后续所有找线找点都基于它

### 指标① 火花塞到某线的距离

- **找线**：火花塞边缘那条线，**卡尺数量调多** + **忽略点数**（极性不明显，点会歪，忽略歪点）→ 运行 → 线找到了
- **找点**：对火花塞中心做一次**模板匹配**（中心圆点）
- **距离**：点到线距离（Distance Point Line）→ 点 + 线都有 → 运行 → 距离出来了

> 💡 老师说这里用卡尺也能测，但"极性确实不好调"，所以用点到线。

### 指标②和③ 两个垂线 + 交点 → 点到垂线的距离（难点）

剩下两个距离**是这节的难点**——要把各自的**垂线**做出来：

1. **找一条线**（要找垂线的那条边）+ **用一个点**（模板匹配出这个点）
2. **做垂线**：`Creation → Perpendicular（垂线）`工具——**线连找出来的线、点连模板匹配的点** → 运行 → 过该点的那条垂线做出来了
3. **另一条垂线同理**：再找一条线 + 再模板匹配一个点 → 再做一条垂线（图像依旧连定位后的图）
4. **找交点**：`Intersection → Line Line（两线交点）`——判断两垂线**有没有交点**，有 → 把点的位置输出
5. **测距离**：交点当**点**，配合已有的线 → 点到线距离（或点到点距离）→ 完成指标②③

> 连线小技巧：工具用得多了、跨度大时，用**右键连接字（连线）**把"模板匹配的 X/Y"直接连到测量工具输入。

## 🧠 一句话总结

1. **测量流程地基是"坐标定位"**：先整体模板匹配 → 再坐标定位 → 之后所有找线找点测量才"跟着目标走"
2. **最大错误点**：模板匹配连了**原图**，其他工具连**定位后的图**——点线坐标不同源，距离测错
3. **找角坑**：手动操纵工具，电脑不知道你要找哪个角；精确指定角要等**脚本/代码**（脚本能定线的方向）
4. **找线精确**：卡尺数量调多 + 忽略点数 → 线更准
5. **难点套路**：垂线（Creation Perpendicular）= 线 + 点；交点（Intersection Line Line）= 两条线；点到线距离 = 点 + 线——**"你有啥给啥"**

## 📚 作业

1. **钻头尖角度**：模板匹配 → 坐标定位 → 找两根线 → 角线工具测夹角（能接受平角/对角情况）
2. **钻头尖到底座距离**：模板匹配匹配尖尖（连定位图）→ 找底座线（卡尺多点）→ 点到线距离
3. **火花塞三个指标**：整体模板匹配 + 坐标定位 → ①点到线距离；②③两条垂线（Perpendicular）+ 交点（Intersection Line Line）+ 点到线距离
4. **动手验证错误点**：故意把模板匹配连原图，看距离怎么测错的——记住这个错法以后避开
