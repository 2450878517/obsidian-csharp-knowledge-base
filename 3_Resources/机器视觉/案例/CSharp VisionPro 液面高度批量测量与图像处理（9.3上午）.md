# VisionPro 液面高度批量测量与图像处理

本节先把多瓶液体的液面高度批量测出来，再用 `CogIPOneImage` 图像处理工具改善液面不明显、气泡干扰和不同图片之间参数不一致的问题。主线仍然是前几节的脚本模式：模板匹配找到每个目标的横坐标，脚本移动 Caliper，读取边缘距离，再把结果标到图像上。

后半段系统认识图像处理工具中的 18 类操作。课堂强调最常用的是灰度加减常数、灰度均衡、灰度形态调整、3×3 中值和像素映射。

## 案例一：多瓶液面高度测量

页面只露出一半的瓶子不参与测量，只测露出一大半、能够看清液面的瓶子。液面高度本质上是固定底边到液面的距离。

### ToolBlock 准备

先用 CogPMAlign 匹配每个瓶子的固定特征。课堂统一选择瓶盖或瓶盖附近的独特区域作为模板，避免把高度不确定的整个瓶身框进模板，减少匹配位置误差。

再加入 CogCaliper 工具：

- 连接图像。
- 手动调整 Caliper 的方向和区域，使它能测到一个瓶子的液面。
- 根据液面的灰度极性设置边缘方向和边缘对宽度。
- 如果液面不明显，先调整 Caliper 的对比度阈值和过滤相关参数。
- 先让一个瓶子测准，再交给脚本批量移动。

### 脚本循环逻辑

每个模板匹配结果只需要它的横坐标，因为 Caliper 的高度方向和区域高度已经提前设置好，脚本只让 Caliper 左右平移。

```csharp
CogPMAlignTool pm1 =
    mToolBlock.Tools["CogPMAlignTool1"] as CogPMAlignTool;
CogCaliperTool caliper1 =
    mToolBlock.Tools["CogCaliperTool1"] as CogCaliperTool;

CogGraphicCollection box = new CogGraphicCollection();
int count = pm1.Results.Count;

box.Clear();
for (int i = 0; i < count; i++)
{
    double x = pm1.Results[i].GetPose().TranslationX;
    caliper1.Region.CenterX = x;
    caliper1.Run();

    double height = caliper1.Results[0].Width;

    CogGraphicLabel label = new CogGraphicLabel();
    label.Text = height.ToString("F2");
    label.Color = CogColorConstants.Blue;
    label.Font = new Font("宋体", 24);
    label.X = x;
    label.Y = 300;
    box.Add(label);
}
```

上面是课堂逻辑的整理示意。不同 VisionPro 版本中 Caliper 的输入和结果属性名称可能不同，要以工具终端里可写的 `Region.CenterX`、结果集合和边缘结果名称为准。

### 结果异常的排查

如果某个瓶子的高度明显偏大或偏小，先打开 Caliper 的 Region 和投影图，观察它实际选择了哪两条边。液面灰度不明显时，可能被气泡、瓶身边缘或背景线干扰。

调整顺序：

- 先检查 Caliper 的区域是否覆盖正确位置。
- 调整对比度阈值，让目标液面边缘更突出。
- 调整过滤一半像素等参数，排除弱边缘。
- 调参后切换多张图片反复检查，确保前一张和后一张都能测准。

课堂中出现过第一张图正常、第二张图异常的情况。这说明只调一个固定阈值可能无法兼顾所有图像，需要先处理图像，再把处理后的图像送给 Caliper。

## 案例二：图像处理工具 CogIPOneImage

在 ToolBlock 工具箱的图像处理分类中加入 `CogIPOneImage`，把原始图像连接进去。它通过一个表格串联多项图像操作，输出处理后的图像，再把这个输出连接给 Caliper。

图像处理的原则是：先用工具界面完成固定的预处理，再用脚本控制需要随目标位置变化的部分。不要让脚本重复处理可以在 ToolBlock 中直接配置好的内容。

## 图像处理工具的 18 类操作

课堂按工具列表逐项演示。以下名称根据屏幕和语音整理，部分中文名称可能因汉化版本不同而略有差异。

| 类别 | 作用 | 课堂要点 |
|---|---|---|
| 加减常数 | 给灰度值或 RGB 平面加上固定数值 | 灰度图设置灰度加数；彩色图设置平面 0、1、2 |
| 乘以常数 | 将灰度值或颜色平面乘以固定倍数 | 类似加减常数，但更容易过曝，通常优先用加减常数 |
| 灰度均衡 | 拉开灰度分布和对比度 | 液面不明显时常用，先增强图像再测量 |
| 灰度形态调整 | 对灰度图做腐蚀、膨胀、开运算、闭运算 | 与 Blob 形态学类似，但处理的是灰度图 |
| 灰度形态调整 N×M | 自定义形态学邻域尺寸 | 默认可理解为 3×3，也可以调成其他 N×M |
| 高斯滤波器 | 对图像做平滑和降噪 | 用于降低细小噪声，参数过大可能损失细节 |
| 高斯采样器 | 以高斯方式重新采样 | 课堂作为图像平滑和采样类操作介绍 |
| 高通滤波器 | 增强边缘和细节，抑制平坦区域 | 常用于锐化，让轮廓更清晰 |
| 3×3 中值 | 用 3×3 邻域的中值替代中心像素 | 主要用于去除孤立噪点 |
| N×M 中值 | 自定义中值滤波窗口 | 窗口越大，去噪能力越强，也越容易抹掉细节 |
| 缺失像素 | 填补图像中的缺失像素 | 完整图像通常用不到，适合有缺损的图像 |
| 乘以常数 | 通过乘法调整灰度明暗 | 与加减常数相近，课堂强调了解即可 |
| 像素映射 | 把输入灰度值替换成指定输出灰度值 | 可提取特征、反色或突出某段灰度范围 |
| 量化 | 减少灰度级数，把连续明暗变成阶梯级 | 用于快速压缩灰度层次 |
| 采样卷积 | 通过可调卷积参数处理图像 | 可视作更灵活的采样和滤波操作 |
| 二次采样器 | 改变图像采样与尺寸 | 可实现类似拉伸或缩放的效果 |
| 其他采样和扩展操作 | 调整图像大小、采样范围或空间平均 | 具体效果依赖参数，课堂要求先理解用途 |

课堂讲解中部分工具名称被语音识别成近音词，使用时应以 VisionPro 工具箱的实际名称和版本帮助为准。

## 重点一：灰度加减常数

灰度值范围通常是 0 到 255。增加灰度加数会让图像变亮，使用负数会让图像变暗。彩色图需要分别对 RGB 对应的平面设置数值。

灰度溢出模式也要注意：

- 饱和模式：超过 255 的值限制为 255，低于 0 的值限制为 0。
- 环绕模式：超过范围后从另一端继续计算，例如接近 255 的灰度继续增加可能回到较小值。

课堂重点是先理解灰度值范围，再根据图像亮度选择加法、减法和溢出模式。

## 重点二：灰度均衡

灰度均衡用于拉伸或重新分布灰度，使目标与背景的差异更明显。液面高度测量中，优先尝试用均衡处理后的输出图像连接给 Caliper。

如果原始液面边缘灰度差异太小，单纯调整 Caliper 阈值可能会在不同图片之间来回失效；先把图像对比度改善，再测量通常更稳定。

## 重点三：灰度形态调整

灰度形态调整和之前 Blob 课程中的形态学操作概念相近，但处理对象变成了灰度图：

- 腐蚀：缩小或削弱亮区域，消除部分细小亮结构。
- 膨胀：扩大或增强亮区域，使区域更连续。
- 开运算：先腐蚀后膨胀，常用于去除毛刺和细小突出物。
- 闭运算：先膨胀后腐蚀，常用于填补小孔洞、连接附近区域。

具体效果和结构元素形状、大小、灰度极性有关，不能脱离实际图像直接套用。

## 重点四：中值与高通

3×3 中值会把中心像素和周围 8 个像素排序，取中间值替换中心像素，适合去掉孤立噪点。N×M 中值让窗口大小可调，但窗口变大后可能损失细节。

高通滤波器增强边缘和高频细节，适合锐化。它会同时放大部分噪声，所以使用后要再次检查 Caliper 是否把噪声当成边缘。

## 重点五：像素映射

像素映射用一个输入灰度值到输出灰度值的表，把指定灰度范围替换成新的值。

可以用来：

- 反色：`output = 255 - input`。
- 二值化：低于阈值的灰度统一输出 0，高于阈值的统一输出 255。
- 压暗亮部或提亮暗部。
- 增强对比度，把目标灰度段映射成更明显的灰度。

它和 Blob、颜色分割有相似的思想：把原图中关注的像素映射成另一种更容易分离或检测的表示。

## 其他图像处理操作

量化会减少灰度级数，把连续的明暗变化压缩成少量等级，便于快速观察或后续处理。缺失像素用于修补不完整图像，完整照片一般不需要。二次采样器可以改变采样和尺寸，类似拉伸或缩放；采样卷积则允许更自由地设置卷积参数。

这些操作先理解用途即可。实际项目中，优先选能直接改善目标与背景差异的处理，避免为了“处理得更多”而连续叠加不必要的滤波。

## 常见错误与排查

- 结果数量为 0：先检查模板匹配输入图像、模板特征和接受阈值。
- Caliper 测错边：打开投影图，确认实际选中的两条边；再调对比度阈值和过滤参数。
- 第一张图正常、第二张图异常：说明固定参数对不同图像不够稳定，应先使用图像处理工具增强或清理图像。
- 图像处理后 Caliper 不工作：检查 Caliper 是否连接了处理工具的输出图像，而不是仍然连接原图。
- 结果标签重复：每次 GroupRun 开始时执行 `box.Clear()`。
- 读取不存在的结果：访问 `Results[0]` 前先确认结果集合有元素。
- 脚本中赋值失败：确认写入的是 Inputs 或可写的 Region 属性；只读的 Results 和显示属性不能赋值。

## 通用流程

```text
原始图像
  ↓
CogIPOneImage 图像增强或清理
  ↓
CogPMAlign 找到每个目标的横坐标
  ↓
脚本遍历匹配结果
  ↓
移动 Caliper 的 Region.CenterX
  ↓
运行 Caliper 并读取边缘距离
  ↓
用标签显示每个高度
  ↓
ModifyLastRunRecord 输出到处理后的图像
```
