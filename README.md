# 📚 我的自生长知识库

> 一套「扔进去就自己会长」的 Obsidian 知识管理系统。
> 核心原则：**查询代替维护，模板代替记忆，AI 代替手工。**

---

## 🗂️ 文件夹结构

| 文件夹 | 放什么 | 例子 |
|--------|--------|------|
| `1_Areas/` | 长期学习的领域 | `CSharp/`（窗体/代码/多线程） |
| `2_Projects/` | 有截止日期、有产出的事 | `视觉测量工具箱` |
| `3_Resources/` | 参考资料、收藏、软件领域 | `机器视觉/`（VisionPro、卡尺、模板匹配） |
| `4_Archives/` | 已完成/不再活跃的内容 | 完结的项目 |
| `5_System/` | 系统文件 | 模板、脚本、附件 |
| `0_Inbox/` | 刚捕获的想法、待整理笔记 | 随手记、临时笔记 |

---

## 📝 笔记的三种状态

每篇笔记的 frontmatter 里有个 `status` 字段，代表它「长多大了」：

| 状态 | 意思 | 什么时候用 |
|------|------|-----------|
| 🌱 `seedling` | 刚种下的种子 | 刚创建、内容还不完整 |
| 🌿 `budding` | 发芽了 | 内容基本完整、结构清晰 |
| 🌳 `evergreen` | 常青树 | 被多次引用、反复打磨、理解深入 |

笔记会随你的复习和补充慢慢「长大」，不用急着一次写完。

## ⚡ 快速操作

### 1. 新建一篇知识笔记

1. `Ctrl + P` 打开命令面板
2. 输入 `QuickAdd`，选择 **📝 新建知识笔记**
3. 输入标题，回车
4. 笔记自动在 `0_Inbox/` 创建，带完整模板

> 也可以设快捷键：设置 → 快捷键 → 搜 QuickAdd → 绑个顺手键

### 2. 快速捕获想法

1. `Ctrl + P` → 选 **⚡ 快速捕获**
2. 输入想法，回车
3. 自动追加到 `0_Inbox/随手记.md`

### 3. 新建领域 MOC

1. `Ctrl + P` → 选 **🗺️ 新建领域 MOC**
2. 输入领域名（如 `Python`）
3. 自动在 `1_Areas/` 创建地图笔记

### 4. 写日记

1. 左侧边栏点日历图标（或 `Ctrl + P` 搜「打开今天的日记」）
2. 自动套用日记模板，底部会列出今天新建和修改的笔记

## 📋 笔记标准格式

### Frontmatter 字段说明

```yaml
---
tags: [CSharp, 基础语法]      # 第一个永远是领域，后面是主题
status: budding               # seedling / budding / evergreen
area: CSharp                  # 所属领域
aliases: [别名1, alias2]      # 方便搜索的中英文别名
related: [笔记A, 笔记B]       # 手动关联的笔记（2-4 篇）
---
```

**标签规则**：第一个标签 = 领域（`CSharp`），第二个 = 大主题（基础语法/流程控制/数据结构/方法/面向对象），后面可加细分标签。

## 🔗 让笔记自己长链接

笔记底部有 **Dataview 自动关联区**，会自己长出来：

1. **反向关联** — 别的笔记在 `related` 里提到你，这里自动显示
2. **同标签笔记** — 标签一样、可能相关的笔记自动列出

所以只要你**写新笔记时填好 `related`**，链接网络就自己织起来了。

## 🧹 每周回顾仪式（15 分钟）

每周日花一刻钟，做这几件事：

1. **清空 Inbox** — 把 `0_Inbox/` 里的笔记归位到对应领域
2. **救救孤立笔记** — 打开 Dashboard，看「孤立笔记」列表，给它们加 1-3 个链接
3. **养养种子** — 挑 1-2 篇 `seedling` 笔记补充内容，升到 `budding`
