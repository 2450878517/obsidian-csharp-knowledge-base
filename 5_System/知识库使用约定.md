# 知识库使用约定

[[Dashboard|返回首页]]

| 位置 | 用途 |
|------|------|
| 0_Inbox | 新笔记、随手记和待整理课程记录 |
| 1_Areas/CSharp | 持续学习的 C# 知识，保留代码/窗体/多线程分区 |
| 1_Areas/机器视觉 | 机器视觉学习地图，连接课堂资料和实践项目 |
| 2_Projects | 有明确产出的项目计划与进度 |
| 3_Resources/机器视觉/知识点 | VisionPro 工具原理、参数、通用代码和排错知识 |`r`n| 3_Resources/机器视觉/案例 | 按产品或课堂项目整理的完整流程 |
| 4_Archives | 已完成且不再活跃的内容，按需归档 |
| 5_System | 模板、脚本、附件和知识库操作说明 |

先收进 Inbox，再按内容归位。领域地图按 area 聚合，文件夹用于存储；机器视觉资料不必为了出现在地图里再复制一遍。

内容笔记填写 tags、area、status、related；第一个标签填领域。新 related 推荐写成 YAML 字符串双链，例如 `related: ["[[CSharp 方法|C# 方法]]"]`，旧的纯标题格式仍可用于关联查询。地图使用 moc 标签，日记使用 daily；项目状态用 active 等，不强行套用知识成熟度。

每周打开 Dashboard，整理收件箱，补充待完善笔记，并更新进行中的项目。移动笔记优先在 Obsidian 中完成，以便更新链接。重命名前检查同名笔记与路径链接。

视频解析保留来源和时间戳。课程记录先用 tpl-video，整理后进入对应领域或资源目录。大视频保留在原位置；笔记链接到它，避免把视频复制进 Git。需要 Word 时可另行导出。

旧脚本 `batch_fm.py` 只用于早期三行 frontmatter 的补齐，默认预览，指定 `--apply` 才写入并备份；不要当作日常批量覆盖工具。
