# C# 面向对象

## 类（class）

类是对象的**图纸**，定义属性和行为。

```csharp
class Student
{
    public string Name;
    public int Age;

    public void SayHello()
    {
        Console.WriteLine($"大家好，我是{Name}");
    }
}
```

## 对象（object）

根据类**造出来**的实际东西：

```csharp
Student s = new Student();
s.Name = "小刻";
s.Age = 10;
s.SayHello();
```

## 结构体（struct）vs 类（class）

| | 结构体（struct） | 类（class） |
|---|---|---|
| 类型 | 值类型 | 引用类型 |
| 赋值 | 复制整个数据 | 传递地址 |
| 修改影响 | 互不影响 | 互相影响 |

```csharp
struct Point
{
    public int X;
    public int Y;
}
```

需要数据独立性时（如复制学生信息）应使用结构体。

## 面向对象四大特征

| 特征 | 说明 |
|---|---|
| **封装** | 提高数据安全、方便维护、降低复杂度 |
| **继承** | 子类复用父类的代码 |
| **多态** | 同一个方法在不同对象上有不同表现 |
| **抽象** | 隐藏实现细节，只暴露接口 |

## 为什么要用类与对象？

1. **🧊 封装**——把相关的数据和行为打包在一块，对外只暴露安全接口，隐藏实现细节
2. **♻️ 复用**——类就像一个模板，可以反复创建对象，不用每次都重写代码
3. **🧩 模块化**——不同功能的代码分散到不同的类里（开车放交通工具类，睡觉放生活类），清晰好管理
4. **🌍 模拟现实**——用对象描述现实世界的东西，代码更直观

> 💡 类 = **图纸 / 模板**，对象 = 用图纸**造出来的实际建筑**
