# C# 运算符

## 算术运算符

| 运算符 | 说明 | 示例 |
|---|---|---|
| `+` | 加法 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 乘法 | `a * b` |
| `/` | 除法 | `6 / 5 = 1`（整数除整数得整数） |
| `%` | 求余 | `6 % 5 = 1` |

**注意**：整数除法得不到小数，需将操作数转为 `float`/`double`：

```csharp
double a = 6.0 / 5.0;  // 1.2
```

## 自增自减

| 写法 | 说明 |
|---|---|
| `++i` | 前置，先自增再参与表达式 |
| `i++` | 后置，先参与表达式再自增 |

## 复合赋值

```csharp
a += 3;   // 等价于 a = a + 3
a -= 3;   // 等价于 a = a - 3
a *= 3;   // 等价于 a = a * 3
a /= 3;   // 等价于 a = a / 3
```

## 关系运算符

```csharp
==   // 等于
!=   // 不等于
>    // 大于
<    // 小于
>=   // 大于等于
<=   // 小于等于
```

**注意**：比较用双等号 `==`，单等号 `=` 是赋值。

## 逻辑运算符

| 运算符 | 说明 |
|---|---|
| `&&` | 与，两个条件同时满足 |
| `\|\|` | 或，任一条件满足即可 |
| `!` | 非，取反 |
