# C# 抽卡模拟器（概率 / 充值 / 保底）

把前面学的随机数、分支、循环、进度条串成一个**抽卡模拟器**——有单抽、十连、充值、保底，三个功能一口气做完。这也是游戏抽奖系统的通用套路。

## 🧩 界面布局（先搭框架）

- **窗体**：`Text` 改「抽奖页面」；`MaximizeBox = False` + `FormBorderStyle = FixedSingle` → 窗口大小固定，用户不能拉大拉小；背景色设灰色
- 上方一个 **GroupBox** 当主体现界面，里面放一个 **PictureBox** 展示本次更新的新角色/武器素材图（立绘）——用户看到好东西才想抽
- 右上角一个 **Label**「点券：xxx」显示余额 + 一个 **Button**「充值 648」
- 充值按钮**下方一个 ProgressBar** 模拟充值过程
- 右下角两个 **Button**：「单抽」和「十连」
- 下方一个 **TextBox** 展示抽奖结果——`ReadOnly = True`（只能看不能写，防作弊：白卡硬说自己抽到红卡）
- 左下角一个 **Label**「保底次数：xx」显示保底还剩多少

> 💡 **父容器属性会传染**：GroupBox 的背景色改了，里面所有控件的背景色默认跟着变（控件继承父容器属性）。不想跟就单独设置那个控件。

**三大功能**：① 抽奖（单抽/十连）② 充值 ③ 保底。老师强调：**先搭好框架，再往里填内容**。

## 🧩 单抽逻辑（随机数模拟概率）

**奖品 + 概率**（老师示例，自己可调）：

| 卡 | 概率 | 随机区间 |
|---|---|---|
| 红卡（最终大奖） | 1% | 1 |
| 金卡 | 4% | 2~5 |
| 紫卡 | 10% | 6~15 |
| 蓝卡 | 25% | 16~40 |
| 白卡 | 60% | 41~100 |

概率怎么模拟？**随机一个区间，按区间判断**——之前学过，直接套：

```csharp
private void btnOne_Click(object sender, EventArgs e)
{
    Random r = new Random();
    int res = r.Next(1, 101);   // 1~100

    if (res == 1)                      // 红卡
    {
        textBox1.Text += "抽到红卡！\r\n";
        MessageBox.Show("抽到大奖了！");   // 大奖给情绪价值
    }
    else if (res >= 2 && res <= 5)     // 金卡
    {
        textBox1.Text += "抽到金卡！\r\n";
    }
    else if (res >= 6 && res <= 15)    // 紫卡
    {
        textBox1.Text += "抽到紫卡！\r\n";
    }
    else if (res >= 16 && res <= 40)   // 蓝卡
    {
        textBox1.Text += "抽到蓝卡！\r\n";
    }
    else                               // 白卡
    {
        textBox1.Text += "抽到白卡！\r\n";
    }
}
```

- 用 `\r\n` 换行，一个结果一行，不挤在一起
- 想要千分率就 `r.Next(1, 1001)`，万分率就 `r.Next(1, 10001)`，区间按比例放大

## 🧩 十连逻辑（把单抽复制十次 + 改三处）

单抽代码复制进循环跑 10 次，但要改**三个地方**：

```csharp
private void btnTen_Click(object sender, EventArgs e)
{
    textBox1.Text = "";   // ③ 每次十连先清空上一次的结果

    for (int i = 0; i < 10; i++)
    {
        Thread.Sleep(100);   // ① 放慢速度，随机数才不重复（循环太快同一种子）

        Random r = new Random();
        int res = r.Next(1, 101);
        if (res == 1)
        {
            textBox1.AppendText("抽到红卡！\r\n");
            MessageBox.Show("抽到大奖了！");
        }
        else if (res >= 2 && res <= 5)
        {
            textBox1.AppendText("抽到金卡！\r\n");
        }
        else if (res >= 6 && res <= 15)
        {
            textBox1.AppendText("抽到紫卡！\r\n");
        }
        else if (res >= 16 && res <= 40)
        {
            textBox1.AppendText("抽到蓝卡！\r\n");
        }
        else
        {
            textBox1.AppendText("抽到白卡！\r\n");
        }
    }
}
```

**要改的三处：**
1. **`=` 改成 `+=`**：单抽用 `=` 会覆盖上一个结果；十连要留着 10 个结果，得**追加**
2. **加 `\r\n` 换行**：一个结果一行
3. **加 `Thread.Sleep(100)` 放慢**：循环太快，`new Random()` 同一种子 → 10 次结果全一样（之前讲过的问题）
4. **每次点十连先清空**：`textBox1.Text = ""`，不然越攒越多

### ⚠️ `+=` 和 `AppendText` 的区别

| 写法 | 效果 |
|---|---|
| `textBox1.Text += "..."` | 循环**全跑完才一次性赋值**，结果一起蹦出来，可能卡一下 |
| `textBox1.AppendText("...")` | **每调一次立即追加**，一个结果一个结果出现，流畅不卡 |

十连用 **`AppendText`**，一个一个蹦出来更好看。

## 🧩 充值逻辑（进度条模拟充值过程）

点券要能加能扣，得是个**字段**（放类里，全局用）：

```csharp
private int money = 0;   // 点券，充值和抽奖都用它
```

充值按钮：点一下不能立马好，用**进度条模拟**充值流程：

```csharp
private void btnCharge_Click(object sender, EventArgs e)
{
    // 进度条初始化：最小值0、最大值120、当前值0
    progressBar1.Minimum = 0;
    progressBar1.Maximum = 120;
    progressBar1.Value = 0;

    // for 循环把进度条充满（每次 +5，循环 24 次 = 120）
    for (int i = 0; i < 24; i++)
    {
        Thread.Sleep(100);      // 放慢，看得见进度条在走
        progressBar1.Value += 5;
    }

    money += 6480;              // 充值 648 → 点券 +6480（1:10 兑换比）
    label1.Text = "点券：" + money;
    MessageBox.Show("充值成功！");
}
```

进度条两种填法：**直接 `Value += 5`**（上面这种，直观），或用 `Step` 属性 + `PerformStep()`（每点一次走一步）。

## 🧩 扣点券逻辑（抽一次花 160）

抽奖得花点券，抽之前判断够不够：

```csharp
// 单抽开头加：
if (money < 160)          // 不够 160
{
    MessageBox.Show("点券不够，请充值！");
    return;               // 不让抽
}
money -= 160;             // 够就扣
label1.Text = "点券：" + money;
```

- 单抽 **160** 点券；十连 **1440**（9×160，**打 9 折**，变相刺激消费）
- **为什么游戏都定 160**：充 648 得 6480 点券，抽一次 160 → 6480÷160 = 40.5 次，抽 40 次**剩 80**，凑不够一抽 → 玩家又充 648。这是策划的套路！
- **为什么充 648**：早年游戏从国外引进，100 美元 ≈ 648 人民币，这个数一直沿用到现在

## 🧩 保底逻辑（脸黑党的救星）

玩家一直抽不到大奖会弃坑，所以要给**保底**——抽够次数必出红卡。保底也是字段：

```csharp
private int bd = 50;   // 保底次数，50 抽必出红卡（自己定）
```

### 单抽保底

```csharp
// 在随机抽奖之前判断保底
if (bd <= 0)                       // 保底次数归零
{
    textBox1.Text += "触发保底，获得红卡！\r\n";
    bd = 50;                       // 保底重置
    label2.Text = "保底次数：" + bd;
    return;                        // 已经给了红卡，后面不用抽了
}
```

- **没触发保底**：正常抽，每次 `bd--`（减1），显示剩余次数
- **抽到红卡**（哪怕是普通抽到的）：`bd` 也要**重置回 50**——不能 49 抽时抽到红卡，第 50 抽还保底红卡，那就无限红了

```csharp
// 抽到红卡的分支里（res == 1）加：
bd = 50;
label2.Text = "保底次数：" + bd;
```

### 十连保底（写在循环里）

十连的保底判断要写进**循环里面**，因为每次抽都得检查（比如保底剩 2，十连第 3 次就可能触发）：

```csharp
for (int i = 0; i < 10; i++)
{
    // ...每次循环开头判断保底
    if (bd <= 0)
    {
        textBox1.AppendText("触发保底，获得红卡！\r\n");
        bd = 50;
        label2.Text = "保底次数：" + bd;
        continue;    // ⚠️ 用 continue 不是 break！
    }
    // ...正常抽奖，抽到红卡也重置 bd = 50
}
```

**⚠️ `continue` vs `break`**：触发保底后**跳过这一次**继续抽剩下的——用 `continue`（跳过当前次）；用 `break` 会**整个十连都中断**，后面几次全不抽了。

## 🧠 一句话总结

**抽卡模拟器 = 随机数区间模拟概率（红1%金4%紫10%蓝25%白60%）+ 单抽用 `=` 十连用 `AppendText` 循环 + 充值靠进度条模拟（字段存点券，抽一次扣 160）+ 保底 50 抽必出红卡（没抽到 `bd--`，抽到红卡或触发保底都重置回 50，十连触发用 `continue`）。**
