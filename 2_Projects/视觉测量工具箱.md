# 🚀 视觉测量工具箱

> 对标 Halcon / VisionPro 的视觉测量工具集，C# + OpenCvSharp + WinForms。
> 工业机器视觉的"饭碗"项目，做出来能写进简历、能现场演示。

## 目标

一套能交互的测量工具箱：加载图像 → 预处理 → 选工具测量 → 叠加标注 → 输出结果。

## 📏 测量类（核心）

- [x] 卡尺工具 Caliper：沿直线扫边缘点，测宽度/直径/间隙（2026-08-15 完成，教程见 [[01-卡尺工具Caliper]]）
- [ ] 圆测量：霍夫找圆 + 最小二乘拟合，输出圆心+半径
- [ ] 直线测量：边缘点拟合直线，输出角度+方程
- [ ] 角度测量：两直线夹角、三点定角
- [ ] 距离测量：点到点、点到线、线到线

## 🔧 标定类

- [ ] 像素当量标定：已知长度物体 → 算出 1像素=多少毫米
- [ ] 相机畸变校正：棋盘格标定，矫正镜头畸变（进阶，可后置）

## 🎛️ 预处理类

- [ ] 灰度化、二值化（固定阈值 + 自适应）
- [ ] 滤波去噪（高斯/中值/双边）
- [ ] 形态学（腐蚀/膨胀/开闭运算）

## 🔍 定位/检测类

- [ ] 模板匹配：找已知物体定位锚点
- [ ] Blob 分析：连通域找区域，输出面积/重心/数量

## 📊 界面与输出

- [ ] 图像显示区：缩放、平移、灰度切换
- [ ] 叠加标注：画十字、画线、画圆、标尺寸
- [ ] 测量结果表 + 合格判定（Pass/Fail 阈值）
- [ ] 导出 CSV

## ✅ MVP（第一版先做这三件）

1. 像素当量标定
2. 卡尺测距
3. 圆/线测量 + 叠加显示
