# C# 值类型与引用类型

程序运行的数据存在内存里，内存分两个核心区：**栈（stack）** 和 **堆（heap）**。值类型和引用类型就住在不同地方，这决定了赋值、传参时完全不同的行为。

## 🧩 值类型 → 存栈上

**值类型**（int、bool、char、结构体 struct、枚举）保存的是**一个具体的值**，小、轻量，存在**栈**上。

| 特点 | 说明 |
|---|---|
| 在哪 | **栈 stack** |
| 存放 | 直接存**值本身**（比如数字 42） |
| 速度 | 特别快 |
| 清理 | 方法执行完、离开作用域**自动释放**，不用管 |
| 比喻 | 便利贴 / 前台吧台的外卖——随用随拿，用完就扔 |

```csharp
int a = 42;   // 42 直接存在栈上
```

## 🧩 引用类型 → 内容存堆、地址存栈

**引用类型**（string、数组、类、List……）本身**比较大**，直接存栈上放不下。所以分成两半：**实际内容存在堆上，堆里那个内容的「地址」存在栈上**。

| 特点 | 说明 |
|---|---|
| 在哪 | 内容存**堆 heap**，地址存**栈 stack** |
| 存放 | 堆里存大对象，栈上存它的**地址** |
| 访问 | 要拿内容得**先按地址找** |
| 清理 | 用完**不会自动消失**，要等**垃圾回收（GC）**定期清理 |
| 比喻 | 后台大仓库——大物件放仓库，前台吧台只记仓库的**货架号** |

```csharp
string name = "张三";   // "张三"存堆上，栈上存它的地址
```

## 🧩 栈 vs 堆 对比

| | 栈 stack | 堆 heap |
|---|---|---|
| 存谁 | 值类型 | 引用类型（大对象） |
| 大小 | 小 | 大 |
| 速度 | 快 | 慢（要找地址） |
| 清理 | 自动 | 需要垃圾回收 GC |
| 比喻 | 便利贴 / 前台吧台 | 后台大仓库 |

## 🧩 类 vs 结构体（回顾）

之前讲过的区别，根子就在这：

- **类 = 引用类型**：`p2 = p1` 之后改 `p2`，`p1` 也跟着变（它们**共享同一个堆里的对象**）
- **结构体 struct = 值类型**：`p2 = p1` 是**复制一份**，改 `p2` 不影响 `p1`

老师的生活例子：张先生的信息抄给理事——类是「理事改内容，张先生也跟着变」（同一个本子）；结构体是「理事抄了一份，改自己的，张先生没影响」（各抄各的）。

## 🧩 装箱与拆箱（boxing / unboxing）

`object` 是所有类型的老大（引用类型）。把值类型塞进 `object`，就是**装箱**；再从 `object` 里取出来变回值类型，就是**拆箱**：

```csharp
int num = 42;
object obj = num;   // 装箱：把 int 包进 object（在堆里包了一层箱子）
int back = (int)obj;   // 拆箱：把箱子拆开，拿回 int
```

可以理解成：装箱 = 把东西**装进箱子**放到堆上；拆箱 = **把箱子拆开**把东西拿出来。

## 🧩 静态区（加载堆）

除了栈和堆，还有一个区域存放 **类型信息本身、静态字段（static）、字符串常量** 等。加了 `static` 的成员不用 new 就能用，就住在这一区。了解一下就行。

## 🧠 一句话总结

**值类型存栈（快、小、自动清），引用类型存堆（大、要地址、靠垃圾回收）。** 类的对象在堆上共享，结构体复制各管各的。

## 📚 作业

1. 创建一个类对象和一个结构体，分别做 `p2 = p1` 再改 `p2`，观察 `p1` 变没变（体会引用 vs 值）
2. 写一个 `int` 装箱成 `object`、再拆箱回 `int` 的例子
3. 想一下：为什么 `==` 比较两个 `new` 出来的类对象永远是 False？（提示：比的是地址）
