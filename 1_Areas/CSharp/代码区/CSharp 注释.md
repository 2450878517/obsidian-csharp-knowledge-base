# C# 注释

注释是写给**人看**的代码说明，编译器不会执行。

## 单行注释

使用 `//` 标注信息或临时禁用某行代码：

```csharp
// 这是一行注释
int a = 10; // 也可以写在代码后面
```

## 多行注释

使用 `/* ... */` 包裹一段文字：

```csharp
/*
  这是多行注释
  可以写好几行
*/
```
