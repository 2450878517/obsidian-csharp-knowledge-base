# C# 开发环境

使用 **Visual Studio** 作为开发工具，界面分为左右两半区域。

## 界面布局

- **左半边**：打开最近使用过的项目或文件
- **右半边**：从存储库下载、打开本地项目、或创建新项目

## 创建项目

创建项目时筛选：
- 语言 → **C#**
- 平台 → **Windows**
- 项目类型 → **控制台应用**

## .NET 版本

| 版本 | 说明 |
|---|---|
| .NET Framework | 旧版，适合学习 |
| .NET Core / .NET | 新版，跨平台 |

初学阶段一般用旧版（.NET Framework）就够了。
