# C# var 隐式类型

平时声明变量都要写类型：`string name`、`int age`。但有时候**不知道要什么类型**——这时候可以用 `var`，让编译器帮你猜。

## 🧩 var 是什么

原本创建变量是这样（知道类型）：

```csharp
string name = "张三";
int age = 24;
List<string> list = new List<string>();
```

但假如你要创建一个**身份证号**，不知道它是字符串好还是数字好？可以用 `var` 先创建，后面编译器根据你给的值**自动推断类型**：

```csharp
var idCard = "110101202604040101";   // 我给了字符串，编译器就把 var 当成 string
```

用 `var` 创建的列表也是一样——你给 `List<string>` 就自动推断成 List：

```csharp
var fruits = new List<string> { "苹果", "香蕉" };   // 编译器自动当 List<string>
```

> ⚠️ **var 不是「无类型」！** 它只是帮你省去写类型，编译出来的代码跟你手写具体类型**完全一样**。变量该是什么类型还是什么类型。

## ⚠️ var 的三条规则

想用 `var` 必须遵守三条，少一条都编译不过：

1. **只能在方法内部使用**——不能当类的字段、成员变量
2. **声明时必须立即赋值**——编译器要靠右边的值推断类型
3. **初始值不能是 null**——`null` 没有任何类型信息，编译器猜不出来

```csharp
var x;            // ❌ 没赋值，报错
var y = null;     // ❌ null 猜不出类型，报错
var z = 42;       // ✅ var 被推断成 int
```

## 🧩 匿名类型：var 的第二个用途

创建**一个临时用的对象**，里面放几个属性，不用专门建类：

```csharp
var stu = new { name = "张三", age = 24 };
Console.WriteLine(stu.name);   // 张三
Console.WriteLine(stu.age);    // 24
```

- 它创建了一个**没名字的临时类型**（编译器自动生成类型名）
- 因为是匿名类型，**只能用 `var` 来保存**（你写不出它的类型名）
- 用完就扔，不用专门定义一个类

## 🧠 什么时候用 var

- ✅ **外部库类型太长**时用——比如后面学**工业相机**，相机类型名一串很长，用 var 省事
- ❌ **不推荐滥用**——代码是写给人看的，你知道什么类型就写什么类型，别偷懒
- 日常写代码，`var` 能用但不推荐，老师讲的例子只是为了帮你理解

## 📚 作业

1. 用 `var` 创建一个 `"张三"` 的字符串、一个 `24` 的整数，分别打印出来
2. 用 `var` 创建一个匿名类型（名字+年龄），打印它的属性
3. 故意写 `var x;` 和 `var y = null;` 看看报什么错，理解三条规则
