# C# 数据类型

## 值类型（存实际数据）

| 类型 | 说明 | 示例 |
|---|---|---|
| `int` | 整数 | `int a = 10;` |
| `float` / `double` | 小数 | `double d = 3.14;` |
| `char` | 单个字符 | `char c = 'A';` |
| `bool` | 布尔值 | `bool b = true;` |
| `decimal` | 高精度（金融计算） | `decimal price = 19.99m;` |

## 引用类型（存地址引用）

- `string` — 字符串
- `class` — 类
- 数组
- `interface`
- `delegate`

## 变量声明

```csharp
int number1 = 10;
string name = "小刻";
double price = 9.99;
```
