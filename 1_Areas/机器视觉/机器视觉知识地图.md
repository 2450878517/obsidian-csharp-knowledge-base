## 统一的排错清单

| 现象 | 先查什么 |
|---|---|
| 取不到工具 | ToolBlock 中的工具名是否完全一致，`as` 转换结果是否为空 |
| 结果顺序不对 | PMAlign 结果通常按匹配结果排列，先取坐标再排序 |
| 数组越界 | 访问 `array[i + 1]` 时使用 `i < count - 1` |
| 图形重复叠加 | 每次运行开始先 `CogGraphicCollection.Clear()` |
| 图形不显示 | 检查 `ModifyLastRunRecord` 的记录路径和图像节点 |
| 标记位置偏移 | 确认工具输入图、定位图、输出图是否使用同一坐标系 |
| 不同案例结果混用 | 核对产品数量、阈值、展开比例，不要直接复用常数 |
